## 仍需完成的验收

1. **真实录音**：换用能明确管理麦克风权限和真实输入设备的浏览器，按用户授权约 10 秒采集并及时结束；再测不同学科热词、时间戳、错误恢复和中央计费。当前只能证明失败后的 UI 可恢复，不能声称 ASR 端到端成功。
2. **视觉生成**：隔离复现模型输出字面 `<tool_call>` 的路径，保证真实 `drawDiagram`/Class `render_visual` 调用能形成可渲染且经过净化的 SVG；医学图需检查标签准确性。图库检索应优先高相关教材图并过滤弱相关外部图片。
3. **多设备同步与内存**：在两个真实浏览器/设备验证导图版本轮询、冲突与笔记同步；采集长课浏览器 retained heap、long task、Worker 与 Electron RSS。现有 Node/JSDOM 结构测试不能替代这些指标。
4. **多媒体与大正文**：真实 PDF/PPTX/视频、病理图片缩放与长文章正文点击加载仍需浏览器逐项验收。
5. **凭证轮换**：本轮读取父目录 MCP 配置时，两枚 Supabase PAT 曾误入本地工具输出。没有写入 Git，但应由凭证所有者立即轮换 RootSolo 与 legacy PAT，并更新父目录 MCP 配置；轮换后复查集成。本文不包含凭证值。
