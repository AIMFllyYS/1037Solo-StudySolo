## 2026-09-13 交付记录

### 工程与架构

- 修复原工作区 64 条 TypeScript 诊断；加入 `typecheck` 命令。
- 保留浏览器认证环境变量的静态内联行为，环境解析输入改为可注入的部分环境值。
- 消息 parts 入口要求 `type`，修复工具结果、来源联合类型与产物压缩边界。
- 删除 11 个无调用的本地辅助函数及不再使用的向量容灾包装、遗留类型；没有删除会话、内容或用户配置。
- 构建额外发现 `can-embed` 路由导出辅助函数不符合 Next.js 约束；原逻辑迁入 `lib/browser/probeEmbed.ts`，路由仅保留入口与配置。

### 模型接入

- `lib/ai/relayConfig.ts` 负责服务端中转配置。内置 relay 默认采用 OpenAI 兼容思考参数，不再默认向中转发送原厂专属的混合字段。
- `RELAY_MODEL_CONFIG` 可按稳定注册 ID 覆盖精确 `apiModelId`、`thinkingRequestStyle` 和 `enabled`；格式验证失败时明确报错。示例见 `.env.example`。真实 `.env.local` 未改。
- DeepSeek / MiMo / Gemini / Anthropic / SiliconFlow / OpenRouter 的方言适配保留；自定义 API 高级设置补全原有方言选项。
- 只读查询企业中转 `/models` 返回 HTTP 200，目录确实包含 `deepseek/deepseek-v4.1-flash`。Qwen3.7 Flash 也出现在目录，但按本次要求暂不进入自动候选。GPT-5.6 Sol 菜单仍保留。
- 没有发送真实生成请求；目录可见不能证明某模型已具备实际生成权限或支持全部参数。

### 自动模式

- `auto` 是选择策略，不是上游模型名称，不能未经路由直接交给 provider。
- `lib/ai/autoRoute.ts` 内部只允许快速/免费候选；先筛选图片能力、工具能力、上下文容量和已配置/启用状态。
- 默认策略按图片、思考偏好及输入长度选择顺序。没有合法候选则明确失败，不升级到多模态/旗舰。
- 候选集合同时约束故障切换；模型不存在的明确错误码可触发同集合内的重试。
- 自动会话标题采用本地标题，历史摘要沿用选定候选，追问采用现有客户端兜底，避免辅助调用落回旧的默认模型。
- 展示记录保留所选 `auto`；服务端费用按实际落地模型记账。内部选择规则不写入用户 UI 或系统提示词。

### 呈现与性能

- 模型选择为“内置模型 → 分类 → 具体模型”，详情/思考选项内联展开；自动、免费、快速、多模态、旗舰按要求排序，生图入口额外保留。用户 API 仍按自定义分组显示。
- 同一面板逐层进入，避免窄屏浮层叠放；加入返回、方向键、Home/End、Escape、触摸操作以及可视区域 resize 支持。
- 流式保存采用 `setItemLazy`：800ms 有界检查点之前不序列化整个会话；完成/停止时刷新保存队列，删除取消待写数据。
- 更新消息时只扫描目标消息的产物，不再扫描整段历史来合并产物 ID。
- 长活跃文本使用 100/200ms Markdown 展示节奏，最终内容立即精确显示；稳定渲染树复用。未移除 HTML/SVG 清洗。
- 滚动跟随由文本/尺寸变化合并触发，忽略透明度/变换动画属性，隐藏页减少工作；保留用户上滚退出跟随。
- 使用现有 TanStack Virtual 的 `useFlushSync: false`，消除生命周期中的同步刷新警告；没有引入新的 UI 库。
- 新增 `data-answer-complete`，主答案完成即停止思考动画，正常追问仍在最终 finish 前到达；取消、错误仍保留部分内容。
- 移除主聊天每次请求前非必要的索引体检；检索索引仍由实际检索路径按需加载。

### 会员与额度

- 新增受认证保护的 `/api/quota`；当前用户仅来自已验证会话，响应 `private, no-store`，服务端复用 `loadQuotaSnapshot`。
- 展示 free/plus/pro、平台模型额度、自备 API 辅助额度、当前额度周期。周期结束不误标为会员到期；辅助池不冒充外部 API 余额。
- 额度数据库读取分页，后续页出错不返回部分余额。超过聚合安全上限时失败，不错误放行。
- 同用户在途请求去重；额度不持久化到本地；切换账号忽略迟到的旧响应。失败不显示伪造的零余额。
- 面板打开、生成终止、兑换、窗口重新激活时刷新；细节折叠后卸载缓存倒计时。浮窗缺数据时不使用主聊天的额度上下文。
