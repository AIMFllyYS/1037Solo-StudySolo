# 系统解剖学 · 第25-26节 复习手卡

> 用法：先看卡片标题回忆，点击展开对照「直接结论 / 深度解析 / 助记口诀」。

## 第一章 肾

:::memory{label="1.1 肾的位置与毗邻" mode="reveal"}
**直接结论**

- **位置**：腹后壁腹膜外间隙（腹膜外位器官），左右各一，形似蚕豆，约 10×6×4 cm
- **肾门**：血管、神经、淋巴管出入处，平对 **第1腰椎体（L1）** 平面
- **高低**：左肾较高（T11 下缘 ~ L2-L3 间）；**右肾稍低**（T12 上缘 ~ L3 上缘，被肝下压）
- **肾区**：竖脊肌外侧缘与第12肋之间的夹角，肾病时叩击痛

**深度解析**

- 左肾前面邻胃底、胰尾、脾血管、结肠左曲、空肠；右肾前面邻肝、结肠右曲、十二指肠降部
- 两肾上方共同被肾上腺覆盖；后方上1/3邻膈，下由内向外为腰大肌、腰方肌、腹横肌

> **助记**：右肾被肝压得低，肾门平 L1，肾区叩痛找竖脊肌外缘与12肋夹角。

:::

:::memory{label="1.2 肾被膜四层（重点）" mode="reveal"}
**直接结论**

- **必背（由内到外）**：基质膜 → 纤维囊 → 脂肪囊 → 肾筋膜
- **基质膜**：紧贴肾实质表面，**与肾实质不可分离**（肾被膜本身不包括它，但须知道）
- **纤维囊**：致密结缔组织+弹性纤维，与基质膜**易剥离**（发生粘连=病理）；肾破裂/手术需缝合此层
- **脂肪囊（肾床）**：包绕肾和肾上腺的脂肪层，保护作用；**肾囊封闭**即将药液注入此层
- **肾筋膜**：最外层，固定肾，分前、后筋膜

**深度解析**

- 肾筋膜上方、外侧缘：前后筋膜相互愈着
- 内侧：后筋膜附于椎体筋膜；前筋膜向对侧移行
- 下方：前后筋膜分离 → **肾下垂**；肾周积脓可沿此向下蔓延至髂窝、大腿根部
- **肾周间隙**：前后筋膜之间，含肾、肾上腺、脂肪及血管，肾周感染局限于此

> **助记**：基质不可离，纤维易剥离，脂肪做封闭，筋膜最外固定肾。

:::

:::memory{label="1.3 肾的构造与肾单位" mode="reveal"}
**直接结论**

- **肾皮质**：浅层，富含血管，肉眼见红色细颗粒——即**肾小体和肾小管**所在
- **肾髓质**：深层，由 15~20 个**肾锥体**构成
- **肾柱**：相邻肾锥体之间陷入的皮质
- **肾单位**：肾的结构和功能单位 = **肾小体 + 肾小管**（肾小体在皮质，肾小管分皮质段与髓质段）

**深度解析**

- 2~3 个肾锥体尖端合并成**肾乳头** → 突入**肾小盏** → 2~3 个肾小盏合成**肾大盏** → 合成**肾盂** → 出肾门后约平 L2 移行为输尿管
- **尿液排出途径**：肾乳头 → 肾小盏 → 肾大盏 → 肾盂 → 输尿管 → 膀胱 → 尿道
- 肾结石可停留于肾小盏、肾大盏、肾盂

> **助记**：皮在外、髓在内；乳头→小盏→大盏→肾盂，像下水道层层汇合。

:::

## 第二章 输尿管、膀胱、尿道

:::memory{label="2.1 输尿管三段与三个狭窄" mode="reveal"}
**直接结论**

- **走行**：成对腹膜外肌性管道，长 20~30 cm，起自肾盂末端（约 L1 上缘），终于膀胱
- **三段**：腹部、盆部、壁内部
- **必背·三个狭窄（结石嵌顿处）**：
  1. 肾盂移行处（起始部）
  2. 跨髂血管/小骨盆上口处
  3. **壁内部（最狭窄）**

**深度解析**

- 输尿管沿腰大肌表面下行，跨髂血管入盆腔，最后斜穿膀胱壁开口于膀胱
- 斜穿膀胱壁形成**阀门样结构**：膀胱充盈时压迫关闭开口，防止尿液反流（否则肾积水）

> **助记**：三个狭窄=起头、跨髂、穿壁；壁内部最窄，结石最爱卡。

:::

:::memory{label="2.2 膀胱与膀胱三角" mode="reveal"}
**直接结论**

- **容量**：正常成人 300~500 mL；空虚时全在盆腔内，充盈时升至耻骨联合上方
- **形态**：膀胱尖、膀胱体、膀胱底、膀胱颈
- **★膀胱三角**：两侧输尿管口与尿道内口之间的三角形区域
- **特点**：缺少黏膜下组织，黏膜平滑无皱襞
- **临床意义**：**肿瘤、结核、炎症好发区**

**深度解析**

- **耻骨上穿刺**：膀胱充盈时，在耻骨联合上方穿刺，腹膜反折被推向上，故不伤及腹膜、不污染腹腔
- 两输尿管口之间的横行皱襞称**输尿管间襞**，是膀胱镜寻找输尿管口的标志

> **助记**：膀胱三角缺黏膜下，平滑无皱，肿瘤结核都爱找它；憋尿后耻骨上穿刺不穿腹膜。

:::

:::memory{label="2.3 女性尿道" mode="reveal"}
**直接结论**

- **女性尿道**：长约 3~5 cm，特点是**短、宽、直**
- **男性尿道**：长约 18~20 cm，分前列腺部、膜部、海绵体部

**深度解析**

- 女性尿道短、宽、直，开口接近阴道前庭，故**易经尿道逆行感染**引起膀胱炎
- 对比记忆：男性尿道有三个狭窄、三个膨大、两个弯曲，走行长而曲折

> **助记**：女尿道短宽直，细菌逆行易发炎。

:::
