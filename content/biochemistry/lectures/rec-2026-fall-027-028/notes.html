第一章 · 酮体代谢KETONE BODIES

酮体：肝脏输出能源的特殊形式

酮体是肝细胞线粒体中由乙酰CoA缩合生成的水溶性能源分子，可透过血脑屏障，供肝外心、肾、脑、骨骼肌在饥饿时利用。

酮体三组分

组成

乙酰乙酸 + β-羟丁酸 + 丙酮

三者总称酮体（Ketone bodies）。正常血浆0.03~0.5 mmol/L。多选题高频考点。

场所

肝内线粒体生成 · 肝外利用

肝脏缺乏利用酶，只产不烧。利用器官：心、肾、脑、骨骼肌。

生成路径（肝线粒体）

2 乙酰CoA ──乙酰乙酰CoA硫解酶──▶ 乙酰乙酰CoA │ +乙酰CoA ▼ ┌── HMG-CoA合酶（★关键酶）──┐ │ ▼ │ HMG-CoA（6碳） │ │ │ HMG-CoA裂解酶 │ ▼ │ 乙酰乙酸 + 乙酰CoA │ │ │ │ β-羟丁酸脱氢酶 自发脱羧 │ ▼ ▼ └── NADH ──▶ β-羟丁酸 丙酮 + CO₂

利用路径（肝外）

激活方式酶组织分布
转硫途径琥珀酰CoA转硫酶心、肾、脑、骨骼肌（四者都有）
硫激酶途径乙酰乙酸硫激酶（耗ATP）心、肾、脑（骨骼肌无此途径）

两种途径都把乙酰乙酸活化为乙酰乙酰CoA，再硫解为2分子乙酰CoA进入三羧酸循环供能。

⚠ 关键区分：HMG-CoA合酶是酮体生成关键酶；HMG-CoA还原酶是胆固醇合成关键酶——不要混。

第一章 · 酮体代谢REGULATION

饱食 vs 饥饿

饱食状态

胰岛素↑ → 酮体↓

胰岛素=抗脂解激素→抑制脂肪动员→血FFA↓→入肝↓→β氧化↓→乙酰CoA↓→酮体↓。

饥饿状态

胰高血糖素↑ → 酮体↑

胰高血糖素=脂解激素→脂肪动员↑→FFA↑→入肝↑→β氧化↑→酮体↑。机体切换脂类供能，节省糖和蛋白质。

丙二酰CoA的"开关"作用

糖代谢旺盛 │ ▼ 乙酰CoA ──ACC──▶ 丙二酰CoA │ ▼ 别构抑制 CPT1（肉碱脂酰转移酶I） │ ▼ 脂肪酸不能进入线粒体 │ ▼ β氧化↓ → 酮体↓（糖多不烧脂）

丙二酰CoA是"糖多"信号：它按住CPT1，阻止脂肪酸进入线粒体氧化，让多余的糖走合成途径。饥饿时丙二酰CoA下降，CPT1解禁，β氧化和酮体生成同时上升。

生理意义

  • 肝输出能源：饥饿时肝脏糖异生补血糖，同时把脂肪酸变成酮体输出供外周。
  • 透过血脑屏障：脑不能直接用脂肪酸，酮体是脑和肌肉的重要替代能源。
  • 节省糖和蛋白质：酮体利用↑→糖利用↓→蛋白质分解↓。短期饥饿减肥早期掉的是肌肉不是脂肪。

第二章 · 甘油三酯合成TG SYNTHESIS

三条路径合成甘油三酯

小肠用甘油一酯途径再吸收，肝和脂肪组织用甘油二酯（磷脂酸）途径，3-磷酸甘油可来自糖酵解或游离甘油。

组织分布

组织途径原料/产物去向
小肠黏膜细胞甘油一酯途径用消化产物甘油一酯+FFA再合成TG，打包乳糜微粒入淋巴
肝脏甘油二酯途径内质网合成，与载脂蛋白组装VLDL入血
脂肪组织甘油二酯途径（从头合成）可完全由糖合成；也可用乳糜微粒/VLDL中的FFA

甘油二酯途径流程

3-磷酸甘油 ──脂酰转移酶（1号位）──▶ 1-脂酰-3-磷酸甘油 │ 脂酰转移酶（2号位） ▼ 磷脂酸（phosphatidic acid） │ 磷脂酸磷酸酶（脱磷酸） ▼ 甘油二酯（DAG） │ 脂酰转移酶（3号位） ▼ 甘油三酯（TG）

3-磷酸甘油来源

来源一

糖酵解 → DHAP

葡萄糖→糖酵解→磷酸二羟丙酮（DHAP）→磷酸甘油脱氢酶→3-磷酸甘油。所有组织都能走这条路。

来源二

游离甘油（甘油激酶）

仅肝、肾有甘油激酶，可直接磷酸化游离甘油。脂肪组织无此酶。

第三章 · 脂肪酸从头合成DE NOVO FAS

胞液中7轮循环生成软脂酸

乙酰CoA经柠檬酸-丙酮酸循环出线粒体，在ACC作用下活化为丙二酰CoA，再由脂肪酸合酶以"缩合→加氢→脱水→再加氢"四步循环7轮，生成16碳软脂酸。

五种原料（多选考点）

碳源

乙酰CoA

二碳单位供体，来自糖有氧氧化（少量来自氨基酸分解）。

能量

ATP

合成代谢耗能，氧化磷酸化提供。

还原力

NADPH

磷酸戊糖途径 + 柠檬酸-丙酮酸循环中苹果酸酶提供。

辅助

HCO₃⁻ + Mn²⁺

碳酸氢根提供CO₂给生物素羧化；锰离子激活ACC（金属酶）。

乙酰CoA出线粒体：柠檬酸-丙酮酸循环

线粒体：乙酰CoA + 草酰乙酸 ──柠檬酸合酶──▶ 柠檬酸 │ 柠檬酸载体出线粒体 ▼ 胞液：ATP-柠檬酸裂解酶 ──▶ 乙酰CoA + 草酰乙酸 │ │ （合成用） 草酰乙酸→苹果酸 │ 苹果酸酶（脱羧+脱氢） │ NADP⁺→NADPH ▼ 丙酮酸 ──丙酮酸载体──▶ 回线粒体

关键酶 ACC

乙酰CoA羧化酶（ACC）：乙酰CoA + HCO₃⁻ + ATP → 丙二酰CoA。辅酶=生物素（携带CO₂），需Mn²⁺。无活性时是单体，10~20个单体聚合成多聚体才有活性。

第三章 · 脂肪酸从头合成ACC REGULATION

ACC的双重调节

调节类型激活抑制
别构调节柠檬酸、异柠檬酸（→单体聚合成多聚体）软脂酰CoA及长链脂酰CoA（产物反馈）
化学修饰（磷酸化）胰岛素→蛋白磷酸酶→去磷酸化→激活胰高血糖素→AMPK→磷酸化→失活
⚠ 记住：磷酸化=失活态。胰高血糖素通过AMPK让ACC磷酸化失活；胰岛素通过磷酸酶让ACC去磷酸化激活。高碳水饮食还能促进ACC基因表达。

脂肪酸合酶（FAS）结构

原核（大肠杆菌）

多酶复合体

7种酶蛋白独立肽链 + ACP，组装在一个complex里。

真核（哺乳类）

多功能酶

一条多肽链上有7种酶活性中心，首尾二聚体才有活性。ACP是其中一个功能域。

ACP（酰基载体蛋白）：辅基=磷酸泛酰氨基乙硫醇（含泛酸），末端巯基（-SH）承载丙二酰CoA。缩合酶（CE）的巯基承载起始乙酰CoA。

7轮循环

起始：CE上挂乙酰CoA(2C)，ACP上挂丙二酰CoA(3C) │ 每轮四步： ① 缩合脱羧（丙二酰基+乙酰基→β-酮脂酰，脱1CO₂，净+2C） ② 加氢（β-酮脂酰还原酶，NADPH） ③ 脱水（脱水酶→α,β-烯脂酰） ④ 再加氢（烯脂酰还原酶，NADPH） │ 丁酰基从ACP转位到CE，ACP接新丙二酰CoA │ 重复7轮 → 16碳软脂酸释放 总耗：1乙酰CoA + 7丙二酰CoA + 14 NADPH

第四章 · 碳链延长与去饱和ELONGATION

从16碳到更长、更不饱和

胞液只合成16碳软脂酸；内质网用丙二酰CoA延长，线粒体直接用乙酰CoA延长；去饱和酶在内质网加双键，但动物缺Δ12/Δ15酶。

两个延长场所对比

特性内质网延长线粒体延长
二碳供体丙二酰CoA乙酰CoA（直接，不需羧化）
还原当量NADPHNADPH
反应过程类似胞液软脂酸合成类似β-氧化逆反应
可延长至C24C24~C26
⚠ 选择题陷阱：线粒体延长直接用乙酰CoA，不用丙二酰CoA。体内最多产物是C18硬脂酸。

去饱和

  • 去饱和酶镶嵌在内质网，脱氢过程类似电子传递链。
  • 动物：Δ4、Δ5、Δ8、Δ9去饱和酶（只能在这些位置加双键）。
  • 植物：Δ9、Δ12、Δ15去饱和酶。
  • 亚油酸（18:2 Δ9,12）和α-亚麻酸（18:3 Δ9,12,15）是必需脂肪酸——动物缺Δ12/Δ15去饱和酶，必须从植物性食物获取。

FAS作为药物靶点

肿瘤患者脂肪酸合酶高表达。FAS抑制剂除了减重抑制脂肪合成，还具有抗肿瘤和抗肥胖的药物潜力。

第五章 · 磷脂代谢开篇PHOSPHOLIPIDS

甘油磷脂合成需要CTP

甘油磷脂在内质网合成，头基（乙醇胺/胆碱）来自丝氨酸，CTP激活生成CDP中间物。

头基合成路径

丝氨酸 ──脱羧──▶ 乙醇胺 │ S-腺苷甲硫氨酸提供3个甲基 ▼ 胆碱 │ ┌───────────────┴───────────────┐ │ ATP(激酶) ATP(激酶) │ ▼ ▼ 磷酸乙醇胺 磷酸胆碱 │ │ CTP（胞苷转移酶） CTP ▼ ▼ CDP-乙醇胺 CDP-胆碱 └───────────────┬───────────────┘ ▼ 甘油磷脂合成
  • 合成部位：全身组织内质网（肝/肾/肠最活跃）。
  • 能量需求：ATP + CTP（常考！CTP激活磷酸头基生成CDP中间物）。
