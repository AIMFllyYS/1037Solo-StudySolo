第1章 小组同族词与课文词汇（cyst 等）

章主旨：按词族串讲 Unit 1 课文医学词，并与第五单元膀胱主题衔接。

1.1 cyst 词族（膀胱）

  • cyst 词根表膀胱；cystitis 为膀胱炎（课文第 15 段）。 〔说话人2 02:50〕
  • interstitial cystitis 为间质性膀胱炎。 〔说话人2 02:50〕
  • cystoplasty 为用肠段扩大膀胱（膀胱成形术，课文第 4 段）。 〔说话人2 02:50〕
  • cystoscopy 为膀胱镜检查；cystoscopic examination 为膀胱镜下检查。 〔说话人2 04:39〕
  • cystectomy 为膀胱切除术；cystotomy 为膀胱造口术。 〔说话人2 04:39〕
  • 第五单元学膀胱外翻，第一单元词汇表已列出相关词，利于疏通词汇。 〔说话人1 04:17〕

1.2 泌尿、临床、再生与血管词族

  • urine 尿液；urinary 泌尿的；urination 排尿。 〔说话人2 05:17〕
  • clinic 诊所；clinical 临床的；clinician 临床医生；preclinical 临床前的。 〔说话人2 05:17〕
  • clinical trials 临床试验（课文第 13 段）；clinically effective 临床有效。 〔说话人2 06:36〕
  • complication 并发症（课文第 3、5、10 段）；complication-related problems 与并发症有关的问题。 〔说话人2 06:36〕
  • angiogenesis 血管生成/血管化（课文第 11 段）。 〔说话人2 07:04〕
  • regenerate（v.）再生；regeneration（n.）再生；regenerative 与再生相关的；regenerated 已再生的（如 regenerated tissue）。 〔说话人2 05:50〕
  • vascularize 使血管化；vascularized 已血管化；vascularization 血管化；cardiovascular 心血管的。 〔说话人2 08:32〕
  • reconstruct/reconstruction 重建；graft/grafting、graft rejection 移植与移植物排斥；augment/augmentation 扩大；colonize 细胞定植。 〔说话人2 08:32〕
词族代表词核心义
cyst-cystitis, cystoscopy, cystectomy膀胱相关
urin-urine, urinary, urination尿/泌尿
clinic-clinical, clinician, preclinical临床
regener-regenerate, regenerative, regenerated再生（分词义不同）

第2章 词根词缀拆解（教材 P6–P13 等）

章主旨：按词根+词缀给出英文构成与中文义，并辨析易混词。

  • diagnosis 诊断；diagnostic 诊断的；diagnostician 诊断医师（-ician 表人）。 〔说话人3 10:33〕
  • electrocardiogram：electro- 电 + cardio 心 + -gram 记录/图 → 心电图。 〔说话人3 10:33〕
  • cardiologist：cardio 心 + -logist 研究者 → 心脏病专家。 〔说话人3 11:44〕
  • internist：intern 内部 + -ist → 内科医生。 〔说话人3 11:44〕
  • urinary tract infection：urin 尿 + -ary + tract 道/途径 + infection → 尿路感染。 〔说话人3 11:44〕
  • palpation：palp 触 + -ation 动作过程 → 触诊。 〔说话人3 13:00〕
  • percussion：per- 彻底 + cuss 叩打 + -ion → 叩诊。 〔说话人3 13:16〕
  • genomic：gen 基因 + -omic → 基因组的；genetic 基因的/遗传学的（需辨析）。 〔说话人3 13:57〕
  • ischemic stroke：is- 停止 + em 血 + -ic → 缺血性卒中。 〔说话人3 14:43〕
  • arteri- 动脉词根；-y 为常见名词后缀（artery 动脉）。 〔说话人3 14:43〕
  • radiologist：radio 射线 + -logist → 放射科医生。 〔说话人3 14:43〕
  • pneumonia：pneumon 肺 + -ia 疾病状态 → 肺炎。 〔说话人3 15:54〕
  • blood clot：blood 血 + clot 块 → 血凝块。 〔说话人3 15:54〕
  • pulmonary embolism：肺词根 + embolize 栓塞 → 肺栓塞。 〔说话人3 16:30〕
  • hypertrophic cardiomyopathy：hyper 过度 + troph 生长 + cardio 心 + myo 肌 → 肥厚型心肌病。 〔说话人3 16:30〕
  • heart failure 心力衰竭；ultrasound：ultra 超过 → 超声波检查。 〔说话人3 16:30〕
  • biometric：bio 生物 + metr 测量 + -ic → 生物测定的。 〔说话人3 17:57〕
  • pathologist：path 病 + -logist → 病理学医生。 〔说话人3 18:37〕
  • fibrosis：fibr 纤维 + -osis 疾病状态 → 纤维化。 〔说话人3 18:37〕
  • ophthalmologist：ophthalmo- 眼 + -logist → 眼科医生。 〔说话人3 19:40〕
  • retinal：retin 视网膜 + -al → 视网膜的。 〔说话人3 19:40〕

第4章 Page 18–19 习题要点

章主旨：按解释拼术语为送分题；语境填空看关键词与专科。

4.1 Page 18 写术语

  • 眼病：ophthalm/o-（眼）词根术语；纤维组织病：fibrosis；心电图记录：electrocardiogram。 〔说话人4 21:00〕
  • 心肌病：cardiomyopathy（cardio + myo）。 〔说话人4 21:30〕

4.2 填空与专科对应

  • 心脏病况转诊 cardiologist；常规体检查心脏开 electrocardiogram。 〔说话人4 23:24〕
  • 视力问题 consult ophthalmologist；评估肾功能选 urinary 相关检查。 〔说话人4 24:30〕
  • 右心到肺氧合再回左心为肺循环 pulmonary；体循环 systemic。 〔说话人4 25:03〕
  • 肺纤维化可致呼吸困难；心肌病需 echo cardiogram 等检查。 〔说话人4 21:54〕
  • 指纹与面部识别门禁属 biometric 系统。 〔说话人4 26:37〕
  • 持续监护生命体征与治疗 → intensive care unit（ICU）。 〔说话人5 27:45〕
  • 理解人体解剖学 anatomy 是有效诊疗的基础。 〔说话人5 27:45〕
  • hypertension 高血压（hyper- 高 + tens- 压 + -ion）；评估者 physician；hyper- 变为 hypo- 即 hypotension 低血压。 〔说话人5 28:37〕
  • 脑损伤相关 → stroke 卒中；timely intervention 与 better outcomes（治疗结果）。 〔说话人5 29:18〕
  • clump of blood 血凝块；可填 thrombosis 或 blood clot；vessel 词根 vas-；artery 动脉、vein 静脉、capillary 毛细血管。 〔说话人5 29:18〕
  • 脑部无创/微创成像 → brain imaging；肺动脉血栓 → pulmonary embolism，危及生命。 〔说话人5 32:16〕

章主旨：先判汉语强调点，再定英文主句谓语；突出内容可用主语从句。

  • 人工智能医院；医疗智能化 intelligentization of medical care。 〔说话人5 33:15〕
  • 机构/技术「问世」宜用 be launched；workflow 工作流程。 〔说话人5 33:15〕
  • 分诊 triage；诊断治疗 diagnosis and treatment；随访 follow-up visits；症状病史 symptoms and medical histories。 〔说话人5 33:56〕
  • 权威治疗方案 authoritative diagnosis and treatment plans；前沿 cutting-edge treatments。 〔说话人5 33:56〕

  • ★考点「标志着新阶段」为主句核心时谓语用 marks，不宜只强调 launched 把 marking 降为状语。 〔说话人1 43:56〕
  • 「尤为突出的是」用主语从句 What is more remarkable is that… 比仅用 notably 更突出。 〔说话人1 46:07〕

第6章 医学英语构词法（六类）

章主旨：除派生法外，老师归纳 conversion、blending、back formation、clipping、acronyms。

  • conversion（词义转换）：contract 普通义「合同」，医学义「患病」contract a disease。 〔说话人1 58:11〕
  • blending（拼缀）：genome = gene + chromosome 组合；需识两个词根。 〔说话人1 58:49〕
  • 拼缀词 breathalyzer = breath + analyzer（呼吸测定器）；pulse oximeter 脉搏血氧测定仪（pulse + ox + -meter）。 〔说话人1 01:00:02〕
  • back formation（逆构）：diagnose ← diagnosis；palpitation → palpate；ovulation → ovulate。 〔说话人1 01:02:00〕
  • clipping：influenza → flu；短形式非正式，全称更正式。 〔说话人1 01:02:00〕
  • acronyms：取首字母且常全大写，如 ICU、ECG。 〔说话人1 01:03:17〕
  • 派生法（整理）：前缀 + 词根 + 连接元音 + 后缀为最常见构词。
助记（整理）：转换拼缀逆构，截短缩略派生。

第8章 Unit 5 导入：膀胱外翻与再生工程

章主旨：词根读懂 exstrophy；区分教材标题与 Nature 原文标题侧重点。

  • 课文 P121：Battling bladder disorder with regenerative engineering；bladder 膀胱。 〔说话人1 01:21:31〕
  • exstrophy：extra- 向外 + troph 生长 → 膀胱外翻（先天性膀胱在腹外）。 〔说话人1 01:23:00〕
  • congenital：con- + gen 基因 → 与生俱来、先天性畸形。 〔说话人1 01:23:51〕
  • 原文标题强调 regenerative engineering、safe way；教材 battling 强调正在进行的治疗行动。 〔说话人1 01:27:04〕
  • 正刊发表不宜用 battling 动名词标题；子刊 Nature portfolio 非 Nature 正刊，本文为 case study。 〔说话人1 01:29:20〕
  • Summers 实验室（Northwestern Medicine）专注儿童膀胱外翻，研究可在线查阅。 〔说话人1 01:30:00〕
  • tissue engineering 组织工程：细胞生物学 + 工程 + 医学的跨学科领域。 〔说话人1 01:31:38〕
  • 病例 Baker：出生约 19 小时首次手术，26 岁在实验室研究八年，研究历程漫长。 〔说话人1 01:32:25〕
  • 创新前须了解 background，避免重复他人二十年前的想法。 〔说话人1 01:32:25〕
  • 学习方法：quantitative practice 量变 → qualitative change 质变；每组精析 3 段，其余段须自觉思考。 〔说话人1 01:34:41〕
  • 第 1 段主旨：引言 + Baker 疼痛经历；写作 quotation 开篇、contrast、narrative medicine。 〔说话人1 01:39:23〕
  • quotation 开篇目的：吸引读者 + 呈现真实 personal experience（症状描述）。 〔说话人1 01:41:18〕
  • 今天的作业要交：Unit 1（一单元）全部作业。 〔说话人1 01:42:21〕
