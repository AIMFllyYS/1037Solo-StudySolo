# 模型选择器与公共表面维护

2026-10-11，按本轮连续反馈在 dev 维护，主线等待用户验收。

## 已落地

- 点击模型先打开紧凑思考卡；点击模型名在固定底部锚点向上展开分类。桌面移动鼠标进入分类后展开三级列表，默认没有详情占位。
- 模型说明使用既有 AnimatedCollapse 在对应行下方展开；能力 SVG 紧跟名称，小卡片与模型行左右对齐。手机通过点击预览与确认选用，保留逐级返回。
- Ask/Full 偏好入口不再被输入框的登录/会话禁用状态连带禁用；发送和身份门控不变。溢出菜单改为透明圆形触发器和纵向选项。
- 滑杆共享弹簧参数，保留原生键盘语义与指针捕获/取消。轨道 26px、滑块 28px，填充和滑块分层，关闭思考时填充为零。
- Fast 在菜单打开期间显示持续加速流动的细粒子；普通和 Fast 模式均复用公共菜单开场扫光。粒子随 Fast/菜单关闭卸载；系统或用户的减少动画设置会停止动效。光效层不接收鼠标事件。
- surfaces.css 统一模型/通用菜单、账户弹层、侧栏账户区、顶部控件条、内容/Agent/窗口页签及设置卡片的填充、圆角、高光和阴影。原横线分组改为留白；长内容列表不逐项添加模糊。

## 验证与边界

- 交互阶段：65 项定向 React、39 项模型/定位/动画测试通过；最终受影响的 27 项再次通过。Ask/Full 切换在隔离测试内验证，实际浏览器确认两个入口与选项均可操作。
- 公共表面阶段：61 项相关组件回归通过；滑杆/菜单/工作区 24 项通过（与前一组有重叠），包含减少动画立即卸载粒子的检查；13 项壳层/菜单检查通过。
- 类型、定向 ESLint、文档链接检查通过。最终隔离生产构建 `.next-perf-surfaces-20261011` 成功生成 1456 页，构建后恢复 tsconfig。内容未改，本轮沿用前次内容和索引门禁。
- 浏览器实测一级到二级时底边不变、顶边向上；悬停行展开时行顶不动；详情卡和模型行左右差值均为 0。三级默认完整显示六个多模态模型，无预览占位。
- 实测轨道 26px、滑块 28px，中心差值为 0；Fast 粒子样式为 infinite/running，普通模式粒子数为 0 且保留菜单扫光。390px 窄屏验证逐级导航和行内详情；没有将浏览器视口模拟称为真实手机触摸验收。
