## 第一章 脂质分类与功能

:::memory{label="1.1 脂质分类（必考）" mode="reveal"}
**直接结论**

- 脂质（Lipids）= **脂肪（Fat）+ 类脂**
- **脂肪 = 甘油三酯（三酰甘油）**：甘油三个羟基被三分子脂肪酸酯化，储能
- **类脂（5种，多选题必考全选）**：①胆固醇 ②胆固醇酯 ③磷脂 ④糖脂 ⑤鞘脂

**深度解析**

- 甘油三酯三个羟基全被烃链取代 → 非极性、脂溶性、不溶于水
- 体内还有少量甘油一酯、甘油二酯（中间代谢物）；**甘油二酯兼作第二信使**
- 按烃链长度分长链/中链/短链甘油三酯

**助记口诀**

> 脂质分脂肪与类脂；类脂五种：胆、酯、磷、糖、鞘。

:::

:::memory{label="1.2 必需脂肪酸与类二十烷酸（高频）" mode="reveal"}
**直接结论**

- **营养必需脂肪酸（人体不能合成，必须食物供给）三种**：
  - **亚油酸**（ω-6，18:2）
  - **α-亚麻酸**（ω-3，18:3）
  - **花生四烯酸**（ω-6，由亚油酸代谢产生，是前列腺素前体）
- **ω-3 / ω-6 / ω-9 三族在体内彼此不能相互转化**；动物只能合成 ω-9、ω-7
- **EPA / DPA / DHA**：深海鱼油成分，DHA 益脑（婴儿奶粉添加），EPA 降甘油三酯

**深度解析**

- 必需脂肪酸可合成三类生物活性物质：**前列腺素（PG）、血栓烷（TXA₂）、白三烯（LT）**
- ★ **PGF 写法规范**：字母（E/F/A…）表示五碳环上取代方式；**下标数字 1/2/3 表示烃链侧链所含双键总数**（如 PGE₁/PGE₂/PGE₃；PGF 系列再标 α/β 位羟基构型，如 **PGF₂α**）。下标数字是双键数，不是"PGF₂₁/₂₂/₂₃"那种编号。
- 血栓烷促血小板聚集→促血栓；白三烯是慢反应物质→与过敏反应有关

**助记口诀**

> 亚油亚麻必需脂，花生四烯前列腺素；ω3/6/9 不互变，鱼油 EPA/DHA。

:::

## 第二章 重要脂质结构

:::memory{label="2.1 甘油磷脂与生物膜（高频）" mode="reveal"}
**直接结论**

- 甘油磷脂：甘油 1、2 位接烃链（两条疏水尾），3 位接磷酸+取代基（极性头）→ 生物膜双分子层骨架
- 常见甘油磷脂（多选题）：
  - 胆碱取代 → **磷脂酰胆碱 = 卵磷脂**（大豆、蛋黄富含）
  - 乙醇胺取代 → **脑磷脂（磷脂酰乙醇胺 PE）**
  - 丝氨酸取代 → **磷脂酰丝氨酸 PS**（正常在膜内表面；**细胞凋亡时外翻**，是凋亡检测标志）
  - 双磷脂酰甘油 → **心磷脂**（线粒体内膜丰富）
  - 肌醇取代 → **磷脂酰肌醇 PIP₂**（第二信使前体）

**深度解析**

- PIP₂（4,5-二磷酸磷脂酰肌醇）被**磷脂酶 C（PLC）**裂解为 **DAG（甘油二酯，激活 PKC）+ IP₃（三磷酸肌醇，促内质网释钙）**，二者均为第二信使

**助记口诀**

> 卵磷脂胆碱、脑磷脂乙醇胺；PS 外翻=凋亡，心磷脂在线粒体。

:::

:::memory{label="2.2 鞘脂与胆固醇" mode="reveal"}
**直接结论**

- **神经酰胺 = 鞘氨醇 + 脂肪酸（酰胺键）**，是鞘脂母体；羟基被糖链取代→鞘糖脂，被磷酸+胆碱取代→鞘磷脂
- **胆固醇母体 = 环戊烷多氢菲**（17 碳刚性结构，极稳定，**不能被彻底氧化为 CO₂+H₂O**）
- 动物胆固醇 = **27 碳**；植物 β-谷固醇 29 碳；酵母麦角固醇 28 碳
- 胆固醇功能：①细胞膜成分 ②转化为胆酸（胆汁酸）③转化为类固醇激素 ④转化为维生素 D₃

**深度解析**

- ★ **胆色素来源（因果别写反）**：胆色素（胆绿素/胆素原/胆素，决定粪、尿颜色）是**血红蛋白（血红素）在衰老红细胞破坏时的降解产物**，经肝随胆汁排入肠道；它**不是**胆汁酸（胆酸）代谢来的。胆固醇→胆酸是另一条通路，二者不要混为一谈。

**助记口诀**

> 胆固醇 27 碳环戊烷多氢菲；胆色素来自血红素，不是胆汁酸。

:::

## 第三章 脂质消化与吸收

:::memory{label="3.1 乳化与消化酶（高频）" mode="reveal"}
**直接结论**

- 消化部位：**小肠上段**
- **乳化**：肝脏把胆固醇生物转化为**胆酸盐（胆汁酸）**，一面亲水一面疏水，把大脂肪滴乳化成**微团**
- 消化酶：
  - 甘油三酯（长链）→ **胰脂肪酶 + 辅脂酶** → 2-甘油一酯 + 游离脂肪酸
  - 磷脂 → 磷脂酶 A₂ → 溶血磷脂 + 游离脂肪酸
  - 胆固醇酯 → 胆固醇酯酶 → 游离胆固醇 + 游离脂肪酸

**深度解析**

- ★ **锚定微团表面、协助胰脂肪酶的是辅脂酶，不是胆酸盐**：
  - **胆酸盐**只负责乳化、把脂肪包裹成微团；
  - **辅脂酶**（胰腺分泌，以酶原形式存在，进十二指肠后被胰蛋白酶切去 N 端 5 肽而成熟）是辅助蛋白（本身无催化活性），靠亲水端结合胰脂肪酶、疏水端结合甘油三酯，把二者拉在一起，并在脂水界面稳定胰脂肪酶构象。

**助记口诀**

> 胆酸盐乳化，辅脂酶锚定；胰脂肪酶+辅脂酶切长链 TG。

:::

:::memory{label="3.2 吸收与两条入血路径（必考）" mode="reveal"}
**直接结论**

- **长链脂类（绝大部分）**：游离脂肪酸+2-甘油一酯+溶血磷脂+胆固醇 → 以混合微团被小肠黏膜上皮吸收 → 胞内**重新合成** TG/胆固醇酯/磷脂 → 与载脂蛋白（**Apo B48/C/A1/A4**）结合 → **乳糜微粒（CM）→ 淋巴管 → 胸导管 → 入血**（绕过肝门静脉）
- **中/短链甘油三酯**：分子小，肠黏膜内继续水解为游离甘油+游离脂肪酸 → **直接经门静脉入血**

**深度解析**

- 小肠黏膜细胞合成甘油三酯走特有途径：**甘油一酯途径**（底物为 2-甘油一酯，经两次脂酰 CoA 转移）；其他细胞走甘油二酯途径
- 对比糖：糖经 SGLT 主动吸收后入门静脉；脂长链走淋巴管，别搞反

**助记口诀**

> 长链乳糜走淋巴，短中直接入门脉；肠黏膜特有甘油一酯途径。

:::

## 第四章 脂肪动员与 β 氧化

:::memory{label="4.1 脂肪动员（名词解释必考）" mode="reveal"}
**直接结论**

- **定义**：脂肪细胞内的甘油三酯在脂肪酶催化下逐步水解为游离脂肪酸和甘油，供其他组织氧化利用的过程（Fat mobilization）
- 部位：**脂肪组织（脂肪细胞）**；产物：1 分子甘油 + 3 分子游离脂肪酸
- 三步水解三个酶：①**ATGL**（+脂滴包被蛋白）②**HSL 激素敏感性脂肪酶 = 甘油二酯脂肪酶** ③甘油一酯脂肪酶
- **关键酶/限速酶 = HSL**（直接受激素磷酸化调控）

**深度解析**

- **脂解激素（促进）**：胰高血糖素、去甲肾上腺素、ACTH、TSH
- **抗脂解激素（抑制）**：胰岛素、前列腺素 E₂、烟酸
- 通路：脂解激素→GPCR→G 蛋白→AC→cAMP→PKA→磷酸化脂滴包被蛋白（暴露 ATGL）+ 直接磷酸化 HSL
- ★ **时机**：脂肪动员在**短期饥饿、空腹过夜时即明显增强**，是饥饿时最先大规模动员的能源；并非"长期饥饿才动员脂肪"。短期饥饿早期先耗尽肝糖原，随后脂肪动员与糖异生并行；长期饥饿时蛋白质分解反而受抑制（蛋白质节俭），脑改用酮体。

**助记口诀**

> 脂肪动员在脂肪细胞，关键酶 HSL；升糖激素促、胰岛素抑；空腹过夜即动员。

:::

:::memory{label="4.2 肉碱穿梭（β氧化限速步）" mode="reveal"}
**直接结论**

- 游离脂肪酸先在胞液活化：脂酰 CoA 合成酶 + ATP → **脂酰 CoA**（耗 2 个高能磷酸键 = 2 ATP）
- 长链脂酰 CoA 不能自由穿过线粒体内膜，需**肉碱穿梭**：
  - **CAT I（肉碱脂酰转移酶 I，线粒体外膜）= β氧化限速酶**
  - 转位酶 + CAT II（内膜侧）配合，把脂酰 CoA 由胞液侧转入线粒体基质侧

**深度解析**

- **丙二酸单酰 CoA**（脂肪酸合成中间物）抑制 CAT I，防止脂肪酸合成与分解同时进行
- 脑组织不能利用脂肪酸；肝把乙酰 CoA 变成酮体供脑（肝内生酮、肝外利用）

**助记口诀**

> 长链脂酰过不了膜，肉碱搬运 CAT I 限速。

:::

:::memory{label="4.3 β氧化四步与能量计算（必考）" mode="reveal"}
**直接结论**

- 部位：**线粒体基质**（除脑组织外各组织可进行，肝、肌肉最旺盛）
- 四步循环（每轮脱 2 碳）：**①脱氢（FAD→FADH₂）→ ②加水 → ③再脱氢（NAD⁺→NADH）→ ④硫解（+CoA → 少 2 碳脂酰 CoA + 乙酰 CoA）**
- Knoop 实验（1904）：偶数碳脂肪酸喂狗尿排苯乙酸，奇数碳排苯甲酸 → 证明从羧基端每次脱 2 碳

**深度解析**

- **软脂酸（16 碳）彻底氧化 ATP 计算（新教材）**：
  - β氧化次数 = 16/2 − 1 = **7 次**
  - 乙酰 CoA = 8 个（每个 10 ATP）= 80
  - FADH₂ = 7 个（每个 1.5 ATP）= 10.5
  - NADH = 7 个（每个 2.5 ATP）= 17.5
  - **生成合计 = 108 ATP；减活化耗 2 ATP → 净生成 = 106 ATP**
- （旧教材按 12 ATP/乙酰 CoA、2/3 计会得 131/129，现以 10/1.5/2.5 新值为准）

**助记口诀**

> 脱氢加水再脱氢硫解；16 碳软脂酸 7 轮、8 乙酰 CoA，生成 108、净 106。

:::

:::memory{label="4.4 奇数碳与超长链脂肪酸" mode="reveal"}
**直接结论**

- **奇数碳脂肪酸**：每次脱 2 碳，最后剩 3 碳 = **丙酰 CoA** →（羧化，生物素）D-甲基丙二酰 CoA →（消旋）L-型 →（变位酶，维生素 B₁₂）**琥珀酰 CoA** → 进入 TCA
- **超长链脂肪酸（≥C22，如 DHA 等）**：先在**过氧化物酶体**中 β 氧化剪短，再回到线粒体彻底氧化
- **不饱和脂肪酸**：天然双键为顺式，需异构酶（顺→反，或 D 型 β-羟→L 型）才能继续 β 氧化
- ω 氧化（内质网）：甲基端氧化为羧基 → α,ω-二羧酸，两端均可 β 氧化（了解）

**助记口诀**

> 奇数碳剩丙酰 CoA→琥珀酰 CoA；超长链先去过氧化物酶体剪短。

:::
