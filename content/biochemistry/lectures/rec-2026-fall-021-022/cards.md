## 第一章 糖原代谢的调节

:::memory{label="1.1 共价修饰的双向调控（高频）" mode="reveal"}
**直接结论**

- **糖原磷酸化酶**：磷酸化 → **a 型（活性↑，促分解）**
- **糖原合酶**：磷酸化 → **b 型（无活性，抑合成）**
- 同一条 **cAMP-PKA** 级联（胰高血糖素/肾上腺素启动）：**分解↑ + 合成↓**

**深度解析**

- 同一激素信号对两个关键酶做出相反的磷酸化修饰，避免"边合成边分解"的无效循环
- PKA 先激活磷酸化酶 b 激酶 → 磷酸化酶磷酸化激活；同时直接磷酸化糖原合酶使之失活

**助记口诀**

> 磷酸化解糖原、磷酸化合酶被抑，一路信号两个反调

:::

:::memory{label="1.2 别构调节与组织差异" mode="reveal"}
**直接结论**

- **肝磷酸化酶**：**葡萄糖是别构抑制剂**（血糖高→直接抑制肝糖原分解）
- **肌磷酸化酶**：**AMP 激活、ATP 抑制**（能量状态直接控制）
- **肌肉收缩时 Ca²⁺** → 激活磷酸化酶 b 激酶 → 分解供能

**深度解析**

- 肝脏要维持血糖，故血糖本身（葡萄糖）就是肝磷酸化酶的别构信号
- 肌肉只为本组织供能，故由 AMP/ATP 的能量荷与 Ca²⁺ 驱动

**助记口诀**

> 肝看葡萄糖、肌看 AMP/ATP，钙一来磷酸化酶就开

:::

:::memory{label="1.3 胰岛素的去磷酸化通路（高频）" mode="reveal"}
**直接结论**

- 胰岛素 → 激活**蛋白磷酸酶 1（PP1）**
- PP1 使**糖原合酶去磷酸化 → 激活合成**
- 同时使**磷酸化酶去磷酸化 → 抑制分解**

**深度解析**

- 进食后血糖升高，胰岛素通过"去磷酸化"这一相反方向，与胰高血糖素的磷酸化通路对冲
- 结果：胰岛素促糖原合成、抑糖原分解

**助记口诀**

> 胰岛素开 PP1，一脱磷酸合酶活、磷酸化酶停

:::

:::memory{label="1.4 糖原累积病（临床）" mode="reveal"}
**直接结论**

- 遗传代谢病，本质是**糖原分解/代谢相关酶缺陷**
- 最常见：**葡萄糖-6-磷酸酶缺陷**（von Gierke 病）→ 肝糖原无法分解为游离葡萄糖 → 肝大、低血糖

**助记口诀**

> 6-磷酸酶缺了，肝糖出不来，肝大又低血糖

:::

## 第二章 糖异生（Gluconeogenesis）

:::memory{label="2.1 概念·部位·底物（高频）" mode="reveal"}
**直接结论**

- **概念**：由**非糖物质**合成葡萄糖/糖原的过程
- **部位**：**肝脏为主**，肾脏次之
- **底物**：**乳酸、甘油、生糖氨基酸**
- **⚠ 脂肪酸不能净生成葡萄糖**

**深度解析**

- 生理意义：饥饿/剧烈运动时维持血糖恒定（脑、红细胞依赖葡萄糖供能）；长期饥饿肾糖异生还参与酸碱平衡（产 NH₄⁺）

**助记口诀**

> 乳酸甘油生糖氨基酸能异生，脂肪酸不行

:::

:::memory{label="2.2 绕过糖酵解三个能障（高频）" mode="reveal"}
**直接结论**

| 糖酵解不可逆反应 | 糖异生替代酶 |
|---|---|
| 丙酮酸 → PEP | **丙酮酸羧化酶 + PEP 羧激酶**（耗 2 高能键） |
| F-1,6-BP → F-6-P | **果糖二磷酸酶-1（FBPase-1）** |
| G-6-P → 葡萄糖 | **葡萄糖-6-磷酸酶**（仅肝/肾有） |

**深度解析**

- 糖酵解有三步放能、不可逆反应，糖异生必须用另外的酶"绕过去"，其余反应可逆共用

**助记口诀**

> 绕三关：羧化酶+PEP羧激酶、FBPase-1、6-磷酸酶

:::

:::memory{label="2.3 丙酮酸羧化支路" mode="reveal"}
**直接结论**

1. 丙酮酸 →（**丙酮酸羧化酶**，辅酶生物素，耗 ATP）→ **草酰乙酸**
2. 草酰乙酸不能自由出线粒体 → 经**苹果酸穿梭**（或天冬氨酸穿梭）到胞液
3. 草酰乙酸 →（**PEP 羧激酶**，耗 GTP）→ **PEP**

**助记口诀**

> 丙酮酸变草酰乙酸，苹果酸出线粒，再花 GTP 变 PEP

:::

:::memory{label="2.4 F-2,6-BP 最强别构调节物（高频）" mode="reveal"}
**直接结论**

- **F-2,6-BP** 是糖酵解/糖异生转换的最强别构调节物
- **激活 PFK-1**（促糖酵解）+ **抑制 FBPase-1**（抑糖异生）
- **胰高血糖素 → 降低 F-2,6-BP → 糖异生↑、糖酵解↓**
- **胰岛素 → 升高 F-2,6-BP → 糖酵解↑**

**助记口诀**

> F-2,6-BP 一把钥匙两方向：胰高血糖素压它走糖异生，胰岛素抬它走糖酵解

:::

## 第三章 乳酸循环与糖醛酸途径

:::memory{label="3.1 乳酸循环（Cori 循环）" mode="reveal"}
**直接结论**

- 肌肉无氧酵解 → **乳酸**入血 → 肝脏**糖异生** → 葡萄糖入血 → 回肌肉
- **意义**：回收乳酸碳源、防止乳酸堆积酸中毒

**助记口诀**

> 肌肉产乳酸，肝脏变回糖，循环回收防酸中毒

:::

:::memory{label="3.2 糖醛酸途径" mode="reveal"}
**直接结论**

- **UDPG → UDPGA（活化葡糖醛酸）**
- 参与肝脏生物转化（结合反应）与糖胺聚糖合成
- 多余葡糖醛酸 → 木酮糖-5-P → 汇入磷酸戊糖途径

**助记口诀**

> UDPG 变 UDPGA，肝脏结合解毒、合成糖胺聚糖

:::
