# Endpoint tariffs and settlement

The central wallet remains the only debit authority. Each SDK candidate now binds its actual server-side provider and upstream model to `lib/billing/trusted-tariffs.json`. A Qiniu model and its Protocom fallback do not share a price simply because their model IDs match. `ECOSYSTEM_ENDPOINT_PRICES_JSON` overrides exact `provider:model` entries, with complete unit/source/version metadata. Model-only overrides cannot change a recognized channel's rate.

All runtime rates are CNY platform credit tariffs. USD quotes were converted with the approved fixed factor 7; this is not live FX or an assertion about supplier invoices. Qiniu DeepSeek is fixed at its approved peak tariff 2 / .04 / 8 (input / read-cache / output per million). MiMo is explicitly an operator tariff with unverified relay supplier cost. Unknown BCAI groups, Qwen tiers and image units remain disabled with explanatory errors.

Token tariff entries have `unit:tokens,currency:CNY,source,verifiedAt,supplierQuoteVerified,price`. Optional tiers use inclusive `maxInputTokens`, strictly increasing, ending with null. GPT Sol aggregate-group thresholds are <=272000 and >272000; Grok uses <=199999 and >=200000. Reservation covers the maximum rate for all possible cache mixes and tiers up to the bounded input. Actual total input including caches chooses the whole-request settlement tier. The immutable complete tariff and conversion ratio are captured in admission metadata. A missing usage record or uncertain outcome stays held, never auto-refunded.

SDK/OpenAI input totals already include caches. Native Anthropic input_tokens excludes read/write cache tokens, so those are added once. Cache read/write partitions are priced separately, with invalid negative or overlapping counts rejected. A cache-write field omitted in an explicitly approved platform tariff uses its normal input tariff; this is platform policy, not a claim that unknown supplier writes are free. Channels requiring unverified differentiated cache units are not enabled.

The installed OpenAI-compatible SDK sets normalized cacheWrite to undefined and may fill missing numeric usage with zero. Settlement therefore validates its preserved raw usage receipt first. Empty raw usage remains unknown; raw cache-write extensions are retained and also normalized back into returned SDK usage, including stream finish events. Automatic model routing filters out pending/unpriced channels before choosing candidates; explicit choices still receive a clear disabled-price error.

Zhipu rerank now uses measured input token pricing, accepting total_tokens for its input-only response. It no longer consumes the fixed `rerank:rerank` request price. Missing usage holds the reservation. SiliconFlow BGE free rerank remains an explicitly zero-priced request service; embeddings use token tariff defaults. Images use an exact provider/model per-image tariff and verified output count (ERNIE 0.11, Z-Image-Turbo 0.10 CNY/image); legacy menu estimates are not debit authority.

Recommended non-secret settings are in Ecosystem `migration-20260927/tariff-runtime-config.json`; no real env was changed here. StudySolo fixed service keys: `search:search_pro`=.03, `search:api.perplexity.ai`=.035, `rerank:BAAI/bge-reranker-v2-m3`=0, `image-search:unsplash`=0 for an eligible app. Do not configure Sonar/Kimi as if one fixed fee covers their token and tool fees. BYOK model infrastructure uses the existing .5CNY/M tariff; missing BYOK service policies remain unavailable.

The classroom AI proxy now uses the same endpoint tariff, cache/tier usage normalization and microcredit settlement. Its terminal SSE frames are held until central settlement succeeds; incomplete or missing usage errors the stream and leaves the reservation held. Existing auth, data ownership and storage mechanisms are unchanged. Classroom capabilities and image-search billing distinguish explicit zero rates from missing rates, matching the existing ASR zero-rate policy.

Platform / my-assets filters operate on actual `asset_index.source_type`, not a separately normalized category. The coordinator's shared type mapping must preserve that distinction when adding new producer types.
