# 登录态与桌面模型菜单修正 · 2026-09-13

本记录补充并取代 STABILIZATION.md 中第一轮菜单交互描述。

## 登录态链路

源码确认的问题：

1. installAiAuthFetch 只覆盖付费 AI 路由，未覆盖 /api/quota、/api/usage、/api/redeem，账户能力依赖 cookie 的偶然有效性。
2. 初始 getSession 异步结果没有版本检查，能够在后续 SIGNED_IN 之后回写旧的未登录状态；readPersistedSession 还会在回写 UI 之前清除 cookie。
3. 原始 Request 对象中的请求头未被继承，可能丢失调用方已携带的认证头。
4. 按路径匹配任意来源的 URL，会向第三方同名 /api/chat 路径附加本站凭证。

修正：

- 本站 AI、额度、账单和兑换统一附加 SDK 当前 access token；保留 Request 头及显式 Authorization，init.headers 仍具有覆盖优先级。
- 严格同源检查，绝不向用户自定义 API 或其他第三方端点追加本站登录凭证。
- 会话读取使用事件版本和读取序号，过时恢复结果不能修改状态或 cookie；迟到 INITIAL_SESSION 不能覆盖已确认登录。
- 先注册认证订阅，再恢复初始状态；窗口激活、页面恢复可见、认证存储变化时重新同步。
- 恢复失败不抹除已有登录状态；退出失败保留原状态；OTP 返回缺少可用 token 时不报告登录成功。
- 请求桥接在 layout effect 安装，先于子组件的被动请求副作用。
- 没有删除、绕过或放宽服务端鉴权。

验证边界：认证服务 settings 只读探测返回 HTTP 200，配置中的前后端 Supabase 地址一致。没有读取用户已有 token，也没有发验证码或使用真实账号登录。

## 桌面模型菜单

- 一级直接显示“内置模型”分组标题，以及自动、免费、快速、多模态、旗舰、生图系列；不再点击“内置模型”进入一页只有系列的菜单。
- 桌面使用同屏级联：一级系列、二级具体模型、三级详情和思考设置并排保留；悬停/点击均可展开，移动到相邻菜单不会自动关闭。
- 三列宽度为 190 / 210 / 224px，列间距 6px；按锚点自动向左或右展开，边缘夹取，独立竖向滚动。
- 桌面行高缩小为 32px，字号 12px；手机保留 44px 触摸行高与单面板逐层进入。
- 自定义 API 分组保持可见，原模型选中、思考选项、训练提示与未来模型保留。
- 方向键、Home/End、Tab、Escape 和焦点恢复有回归覆盖。
