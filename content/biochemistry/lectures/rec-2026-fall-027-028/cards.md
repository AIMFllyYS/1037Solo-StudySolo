## 第一章 酮体代谢

:::memory{label="1.1 酮体的组成与定义（高频·名词解释）" mode="reveal"}
**直接结论**

- **酮体 = 乙酰乙酸 + β-羟丁酸 + 丙酮（三者总称）**
- 英文：Ketone bodies
- 正常血浆：0.03~0.5 mmol/L
- 生成部位：肝细胞**线粒体**
- 利用部位：心、肾、脑、骨骼肌（**肝本身不利用**）

**深度解析**

- 脑组织不能直接利用游离脂肪酸（脂酸不能过血脑屏障），肝脏将脂肪酸转为酮体，酮体可透过血脑屏障供脑利用。
- ⚠️ **肝内生成、肝外利用**——肝脏缺乏琥珀酰CoA转硫酶和乙酰乙酸硫激酶，所以肝自己不烧酮体。

**助记口诀**

> 酮体三兄弟：乙酰乙酸、β-羟丁酸、丙酮；肝生成、肝外用，脑靠它供能。

:::

:::memory{label="1.2 酮体生成反应路径（肝线粒体）" mode="reveal"}
**直接结论**

1. 2 乙酰CoA → 乙酰乙酰CoA（乙酰乙酰CoA硫解酶）
2. 乙酰乙酰CoA + 乙酰CoA → **HMG-CoA**（**HMG-CoA合酶 = 关键酶**）
3. HMG-CoA → 乙酰乙酸 + 乙酰CoA（HMG-CoA裂解酶）
4. 乙酰乙酸 → β-羟丁酸（β-羟丁酸脱氢酶，NADH供氢）
5. 乙酰乙酸 → 丙酮 + CO₂（自发脱羧，不需酶）

**深度解析**

- ⚠️ 关键酶是 **HMG-CoA合酶**（合成酮体），**不是** HMG-CoA还原酶（那是胆固醇合成的酶）。

**助记口诀**

> 两乙缩成乙酰乙酰，再加一乙成HMG，裂解出乙酰乙酸，还原脱羧成β-羟丁酸和丙酮。

:::

:::memory{label="1.3 酮体利用的两条酶途径" mode="reveal"}
**直接结论**

- 乙酰乙酸必须先活化为乙酰乙酰CoA，再硫解为 2 乙酰CoA 进 TCA。
- **转硫途径**：琥珀酰CoA转硫酶——心/肾/脑/骨骼肌都有
- **硫激酶途径**：乙酰乙酸硫激酶——心/肾/脑有，**骨骼肌无**

**深度解析**

- ⚠️ 骨骼肌只有转硫酶途径；心、肾、脑两条途径都有。这是选择题爱考点。
- 硫激酶途径消耗 ATP（2 个高能磷酸键）；转硫途径是把琥珀酰CoA 的 CoA 转给乙酰乙酸，自身变琥珀酸。

**助记口诀**

> 转硫酶四个脏器都能干，硫激酶骨骼肌没有它。

:::

:::memory{label="1.4 酮体的生理意义" mode="reveal"}
**直接结论**

- **酮体是肝输出能源的形式；可透过血脑屏障；节省糖和蛋白质。**
- 饥饿时脑/肌肉靠酮体供能，减少糖消耗，维持血糖
- 酮体利用↑ → 糖利用↓ → 蛋白质分解↓

**深度解析**

- 短期饥饿减肥早期消耗的是蛋白质不是脂肪，因为脂肪动员后酮体还没上来。

:::

:::memory{label="1.5 酮体生成的调节" mode="reveal"}
**直接结论**

- **饱食**：血糖高 → 胰岛素↑（抗脂解）→ 脂肪动员↓ → FFA↓ → β氧化↓ → **酮体↓**
- **饥饿**：血糖低 → 胰高血糖素↑（脂解）→ 脂肪动员↑ → FFA↑ → β氧化↑ → **酮体↑**
- **关键节点**：丙二酰CoA 别构抑制 CPT1 → 阻脂肪酸入线粒体 → β氧化↓ → 酮体↓

**深度解析**

- 糖代谢旺盛 → 乙酰CoA多 → 激活 ACC → 丙二酰CoA↑ → 抑制 CPT1 → 脂肪酸不能进线粒体 → 不烧脂、走合成。

**助记口诀**

> 饱了胰岛素来了酮体少，饿了胰高糖素酮体飙；丙二酰CoA按住CPT1，糖多的时候不烧脂。

:::

## 第二章 甘油三酯合成

:::memory{label="2.1 两条合成途径的组织分布（高频·选择）" mode="reveal"}
**直接结论**

- **甘油一酯途径 = 小肠黏膜细胞；甘油二酯途径 = 肝脏 + 脂肪组织。**

**深度解析**

- 小肠：用消化吸收的甘油一酯 + FFA 再合成 TG（上节讲过）。
- 肝：内质网合成 TG，与载脂蛋白组装成 VLDL 入血。
- 脂肪组织：可完全由糖合成 TG，也可用乳糜微粒/VLDL 中的 FFA。

**助记口诀**

> 小肠走一酯，肝脂走二酯。

:::

:::memory{label="2.2 3-磷酸甘油的两个来源" mode="reveal"}
**直接结论**

- **来源1**：糖酵解 → DHAP →（磷酸甘油脱氢酶）→ 3-磷酸甘油
- **来源2**：游离甘油 →（甘油激酶，肝/肾才有）→ 3-磷酸甘油

**深度解析**

- ⚠️ 脂肪组织没有甘油激酶，不能直接利用游离甘油；肝/肾才有。

:::

:::memory{label="2.3 甘油二酯途径流程" mode="reveal"}
**直接结论**

- 3-磷酸甘油 → 1-脂酰-3-磷酸甘油 → **磷脂酸** → 甘油二酯 → 甘油三酯
- 关键中间物：磷脂酸（phosphatidic acid）
- 脱磷酸酶：磷脂酸磷酸酶

:::

## 第三章 脂肪酸从头合成

:::memory{label="3.1 合成原料五种（高频·多选）" mode="reveal"}
**直接结论**

- **乙酰CoA + ATP + HCO₃⁻ + NADPH + Mn²⁺**
- 乙酰CoA：二碳单位供体（来自糖有氧氧化/氨基酸分解）
- NADPH：还原当量（来自磷酸戊糖途径/柠檬酸-丙酮酸循环）
- Mn²⁺：金属激活剂（ACC 是金属酶）
- HCO₃⁻：提供 CO₂（羧化用）

**深度解析**

- 除 Mn²⁺ 外，四种原料均可来自糖代谢——所以高糖饮食也能胖。

**助记口诀**

> 乙酰ATP碳氢根，NADPH加锰离子，五样原料凑齐了。

:::

:::memory{label="3.2 乙酰CoA出线粒体：柠檬酸-丙酮酸循环" mode="reveal"}
**直接结论**

- 线粒体乙酰CoA + 草酰乙酸 → 柠檬酸 → 出线粒体 → 胞液中 ATP-柠檬酸裂解酶拆成乙酰CoA + 草酰乙酸
- 回线粒体：草酰乙酸 → 苹果酸 → 苹果酸酶脱羧脱氢（产 NADPH）→ 丙酮酸 → 丙酮酸载体回线粒体

**深度解析**

- ⚠️ 乙酰CoA 不能直接穿过线粒体膜，必须以柠檬酸形式带出。这是单选题高频。

:::

:::memory{label="3.3 关键酶：乙酰CoA羧化酶（ACC）" mode="reveal"}
**直接结论**

- 反应：乙酰CoA + HCO₃⁻ + ATP → **丙二酰CoA**
- 辅酶：**生物素**（携带 CO₂）
- 激活形式：10~20 单体聚合成多聚体（60~80 万 Da）

**深度解析**

- ACC 是脂肪酸合成的限速酶，丙二酰CoA 的浓度决定合成流量。

:::

:::memory{label="3.4 ACC的别构调节" mode="reveal"}
**直接结论**

- **别构激活**：柠檬酸、异柠檬酸（单体→多聚体）
- **别构抑制**：软脂酰CoA（C16）及长链脂酰CoA（产物反馈）

**深度解析**

- 柠檬酸从线粒体带出乙酰CoA，同时别构激活 ACC——底物信号转成合成信号。

:::

:::memory{label="3.5 ACC的化学修饰调节（难点）" mode="reveal"}
**直接结论**

- **磷酸化 = 失活；去磷酸化 = 激活。**
- 胰高血糖素：激活 AMPK → ACC 磷酸化 → **失活** → 脂肪合成↓
- 胰岛素：激活蛋白磷酸酶 → ACC 去磷酸化 → **激活** → 脂肪合成↑

**深度解析**

- ⚠️ 爬坡题：磷酸化位点在 Ser1200/1215，由 AMPK 催化。

**助记口诀**

> 胰岛素去磷酸化把酶开，胰高糖素磷酸化把酶关。

:::

:::memory{label="3.6 脂肪酸合酶（FAS）结构" mode="reveal"}
**直接结论**

- 原核：多酶复合体，7 种酶蛋白独立肽链 + ACP
- 真核：**多功能酶**，一条多肽链上有 7 种酶活性中心，二聚体才有活性
- ACP：酰基载体蛋白，辅基 = 磷酸泛酰氨基乙硫醇，末端巯基承载丙二酰CoA

**深度解析**

- ⚠️ 真核 FAS 不是一个酶一个功能，是一条肽链多个功能域。考试爱考这个差异。

:::

:::memory{label="3.7 软脂酸合成的循环过程" mode="reveal"}
**直接结论**

- CE 巯基：起始乙酰CoA（2 碳）
- ACP 巯基：丙二酰CoA（3 碳）
- 四步循环：缩合脱羧 → 加氢 → 脱水 → 再加氢
- 每轮：延长 2 碳，耗 2 个 NADPH
- 循环轮数：**7 轮** → 生成 16 碳软脂酸
- 总 NADPH：**14 分子**

**深度解析**

- 与 β-氧化逆反应类似，但在胞液进行，酶是 FAS，还原剂是 NADPH 不是 FAD/NAD⁺。

**助记口诀**

> 缩合脱羧加两碳，加氢脱水再加氢，七轮下来十六碳，十四个NADPH不能少。

:::

:::memory{label="3.8 碳链延长与去饱和" mode="reveal"}
**直接结论**

- 内质网延长：二碳供体 = 丙二酰CoA，NADPH，可至 C24
- 线粒体延长：二碳供体 = **乙酰CoA**（不是丙二酰CoA！），可至 C24~26
- 去饱和酶：在内质网，动物 Δ4/5/8/9

**深度解析**

- ⚠️ 线粒体延长直接用乙酰CoA，不用丙二酰CoA——这是选择题陷阱。
- 动物缺乏 Δ12/Δ15 去饱和酶，所以亚油酸、α-亚麻酸是必需脂肪酸。

:::

:::memory{label="3.9 为什么高糖饮食也会胖（简答）" mode="reveal"}
**直接结论**

- 所有合成原料均可来自糖：
  - 乙酰CoA ← 糖有氧氧化
  - NADPH ← 磷酸戊糖途径
  - ATP ← 氧化磷酸化
  - HCO₃⁻ ← CO₂ 水合
  - 3-磷酸甘油 ← 糖酵解 DHAP

**深度解析**

- 糖 → 乙酰CoA → 丙二酰CoA → 软脂酸 → 与 3-磷酸甘油缩合 → TG 储存。

:::

## 第四章 磷脂代谢开篇

:::memory{label="4.1 甘油磷脂合成要点" mode="reveal"}
**直接结论**

- 合成部位：全身组织**内质网**（肝/肾/肠最活跃）
- 能量需求：ATP + **CTP**（常考！）
- 关键中间物：CDP-乙醇胺、CDP-胆碱
- 头基来源：丝氨酸 → 脱羧 → 乙醇胺 →（加 3 个甲基）→ 胆碱

**深度解析**

- ⚠️ 磷脂合成需要 CTP，不是 ATP 单独搞定；CTP 激活磷酸乙醇胺/磷酸胆碱生成 CDP 中间物。

**助记口诀**

> 丝氨酸脱羧变乙醇胺，加三个甲基变胆碱，CTP激活成CDP，磷脂就合成了。

:::
