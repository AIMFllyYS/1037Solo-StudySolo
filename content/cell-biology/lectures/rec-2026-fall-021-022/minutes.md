> **主题**：微丝调控因子复习、成核因子 Arp2/3/Formin、上游小GTPase信号、伪足类型、李斯特菌运动、中性粒细胞趋化

---

## 一、复习：微丝基础

### 极性
- **正端 barbed end**（带刺端）：易结合游离肌动蛋白单体，负责**生长**
- **负端 pointed end**（点状端）：结合单体能力弱，负责**解聚**

### 临界浓度（Critical Concentration, Cc）
- 游离 G-actin 浓度 > Cc → 正端生长
- < Cc → 负端解聚
- = Cc → 一端生长一端解聚，净长度不变 = **踏车现象（treadmilling）**

## 二、微丝调控因子四大类（复习+深入）

| 类别 | 蛋白 | 作用 |
|---|---|---|
| **单体结合** | Profilin | 促进单体加入正端（聚合↑） |
| | Cofilin（老师口误cytosin） | 结合单体抑制聚合 |
| **解聚调控** | Gelsolin | 结合Ca²⁺后活化，结合微丝中部**切断** |
| | **Cofilin** | 结合ADP-actin（负端区），促进负端解聚 |
| **稳定性调控** | Stathmin | 均匀结合表面，压低整体动态 |
| | **CapZ** | 结合正端，封端→抑制生长 |
| | Tropomodulin | 结合负端，封端→抑制解聚 |
| **成核因子** | **Arp2/3** | 形成分支状微丝（70°夹角） |
| | **Formin** | 形成线性微丝 |

> 🔑 **CapZ 结合正端**（老师强调会考）；Tropomodulin 结合负端。

## 三、成核因子深入

### Arp2/3（分支状微丝）
- Arp2/3 模拟肌动蛋白二聚体作为**成核引物**，克服成核限速步骤
- 固定在微丝**负端**，不移动；正端向前生长
- 形成 70° 夹角的分支网络

### Formin（线性微丝）
- 始终位于微丝**正端生长端**，随单体加入向前移动
- 产生丝状伪足（filopodia）

### 上游调控：NPF（成核促进因子）
- **WASP / WAVE(=SCAR)**：结合 Arp2/3，使其从非活性变活性
- 正常时 Arp2/3 无活性；信号来→NPF结合→Arp2/3构象改变→成核

### 小 GTPase 级联
- **Rac → WAVE → Arp2/3 → 分支状微丝 → 片状伪足(lamellipodia)**
- **Cdc42 → WASP → Arp2/3 → 丝状伪足(filopodia)**
- **Rho → Formin → 应激纤维(stress fiber) → 细胞贴壁**
- GTPase 结合 GTP=活化，GDP=失活

## 四、李斯特菌运动模型（★金标准：体外重建）

老师强调：**真正理解一个生命过程的金标准 = 在体外用最小组分重建该过程**。

体外重建李斯特菌运动仅需：
1. 微丝（G-actin）
2. **Arp2/3 complex**
3. **CapZ**（封正端）
4. **Cofilin**（解聚循环）
5. **ActA 蛋白**（细菌表面）

### 关键机制
- **ActA 蛋白**：细菌表面跨膜蛋白，结构模拟宿主 **WASP/WAVE** → 直接激活 Arp2/3
- **CapZ 作用**：封支端，防止分支扩展浪费资源，把聚合力集中在细菌-微丝界面
- **Cofilin 作用**：解聚旧微丝→回收G-actin单体→维持正端浓度>Cc
- 微丝长度恒定（踏车），推动细菌前进

> 🔑 老师金句："不是敲基因看表型才叫科研；能用最小组分重建过程才是 good science。"

## 五、三种细胞表面突起

| 突起 | 英文 | 微丝类型 | 上游信号 |
|---|---|---|---|
| 片状伪足 | Lamellipodia | Arp2/3分支状 | Rac |
| 丝状伪足 | Filopodia | Formin线性 | Cdc42 |
| 应激纤维 | Stress fiber | Formin线性束 | Rho |

- Cdc42 激活→细胞表面"炸毛"状刺突=丝状伪足
- Rac 激活→细胞边缘皱褶=片状伪足
- Rho 激活→胞质内贯穿微丝束=应激纤维，助细胞贴壁

## 七、老师强调的考点

1. 微丝极性：正端生长/负端解聚
2. 踏车现象条件：浓度=Cc
3. Arp2/3 vs Formin：分支 vs 线性；固定负端 vs 跟随正端
4. NPF = WASP/WAVE，激活 Arp2/3
5. 小GTPase三兄弟：Rac→片状伪足；Cdc42→丝状伪足；Rho→应激纤维
6. CapZ 封正端；Tropomodulin 封负端
7. 李斯特菌 ActA 模拟 WASP
8. 体外重建金标准
