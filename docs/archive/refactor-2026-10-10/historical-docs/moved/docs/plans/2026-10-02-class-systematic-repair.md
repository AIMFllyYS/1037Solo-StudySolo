## 总目标与交付边界

Class 成为可可靠保存、有明确学科与来源、支持公式、答案、可视化和持续笔记的统一课堂工作台。所有修复先写可复现期望行为测试，再改变实现；审查探针保留为旧基线记录，修复后的正式回归不再断言旧错误。

本轮授权包括本项目代码、测试、文档和待应用迁移。部署、生产数据库执行、真实计费调用不由本地测试推断完成；任何外部验收结果单独记录。`1037Solo-Classolo/`为参考来源，不作为修改目标。保持canonical Auth、owner隔离、MFA与中央计费规则。

## G1：数据和音频可靠性

### G1.1 导图往返与并发

- 共用有版本schema，保留parentId/sourceSegmentIds，验证重复ID、孤儿、环、来源与长度。
- 独立hydrate，原样恢复revision；正常修改才递增。
- 服务端使用数据库原子CAS保存：expectedRevision匹配才写，返回当前revision或409；不能先读后写。
- operationKey写入同一原子操作，已成功请求可安全重放，内容不同的同key不能复用。
- 首次旧格式pending兼容：升级为显式expectedRevision；不把版本未知的本地草稿静默覆盖云端。
- 冲突保留本地草案，允许明确采用云端或重发本地；不同session/owner响应不得污染当前页面。

### G1.2 本地缓存和文稿

- 首先修await前取整包、await后覆盖竞态；返回后读取最新缓存，使用session版本/本地修订判断是否合并。
- flusher强制等待在途任务并drain队列；定时落库；批次最多100行；成功确认后才清理。
- 永久保留segment ID。显示合并与持久化分离。
- 溢出缓存追加去重、可以重放；写失败明确提示，未持久化队列不可被新课attach丢弃。
- 后续实体级IndexedDB事务迁移保留v1读取兼容，避免一次替换造成数据不可见。

### G1.3 录音和ASR任务

- 重采样保留跨帧分数相位/尾样本，验证48k/44.1k/16k及不规则帧；采集电平节流。
- 音频采集持续产生有界分段，串行识别不再使分段超过一分钟；在途/待处理状态独立。
- 段级音频job固定ID、请求ID、开始结束时间与结果状态。已知拒绝可重试，未知结果先核对；人工重转明确提示。
- start/stop重入保护、初始化失败清理、设备断开封尾；停止完成后才发布stopped与ended。
- 参数完整验证先于credit reserve；未知上游结果继续保留既有核对口径。

## G2：导图和更新

- 从已处理片段游标读取新final，以已有树+新文稿生成结构化patch。保留全课节点，稳定ID独立于标题。
- maxWait + single-flight + dirty追赶；session/owner作用域、AbortSignal与generation共同防旧结果。
- 每个节点有sourceSegmentIds，回跳明确切到文稿视图；旧树未有来源时不伪造锚点。
- 节点布局一致计算，增量插入不重合；默认尊重手动viewport，新增节点只提示。
- 云端通过revision查询/可见页面poll提供更新接收，并处理离线重连；真实WS能力独立标注，不把poll包装成推送。
- 主Agent当前检索在云端失败时仍能用本课实时尾部；来源确认与检索权限维持owner过滤。

## G3：学科与公式

课堂taxonomy分为语言文学、数学统计、物理工程、化学生命、医学、人文社科、计算机、其他跨学科；二级医学分解剖/组胚/生理/病理/药理/微生物免疫/临床。通过materialSubjectId关联现有教材registry。

session保存discipline/subdiscipline/语言/课名/资料subject；预置词+本课词+已确认自定义词按主题优先级有界组合，记录实际启用与截断。

保存rawText、校正候选、已采纳校正与revision。专业同音词、数字、单位、否定词不自动改；可确认、撤回、加入本课词库，改动使派生产物标记待更新。

公式候选存spokenText/latex/alternatives/变量/来源/渲染状态/语义状态。KaTeX parse只标可渲染，语义与量纲/等价检查另列；歧义必须显示。统一mhchem能力声明，分子结构用SMILES/RDKit。数学、化学、医学例子分别验收。

## G4：答案和视觉产物

- 题目有assessmentId、课堂/来源revision、题型、选项、答案、解析、尝试状态；开放题也有提示/参考答案入口。
- 题卡内结果流式显示并持久化；追问复用主Agent且绑定本课，不仅发送普通拼接字符串。
- VisualArtifact结构统一图片/原始SVG/函数/分子/结构化说明；复用现有Canvas净化和错误诊断。
- 搜图在任务执行层调用一次，固定结果URL/作者/来源/许可与请求记录；挂载只渲染，不再次计费。
- 区分真实资料与AI示意；优先教材图库，provider能力按当前配置展示，无结果/错误不伪装。

## G5：笔记与复习

- ClassSession关联稳定noteId，一篇持续编辑笔记；AI建议与手写分块，采纳/忽略/撤销，不自动覆盖手写。
- 导出完整层级、公式、视觉、题答及来源；重复保存可更新已有或明确另存。
- 全课按主题处理/归并，不只末尾20段。录音finalization完成再生成，succeeded后标完成，失败可重试。
- 卡片带真实学科/classSessionId/sourceSegmentIds，异步任务完成前重新检查owner/session。

## G6：工作台与性能

桌面：可折叠课堂库 + 主区[笔记/文稿/导图/资料] + 上下文助教；临时对照窗可关闭。顶部课名/学科/状态，低频导出归菜单。统一ClassSelection在文稿、节点、公式、视觉与问答之间流动。

手机：底部[笔记/文稿/导图/提问]，课堂库/资料抽屉；录音操作与保存状态可见，Agent始终可达。中间布局按容器宽度适配，不只看window。

回看解除自动跟随，新增内容提示；生成不抢焦点、不改变用户缩放；长列表虚拟化/按需挂载；电平10–20Hz；昂贵解析/布局按版本合并，用户提问优先于后台补充。
