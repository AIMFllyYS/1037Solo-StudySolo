## 课堂导入：上节回顾

老师开场用约 5 分钟快速回顾了上节课内容，这些是本节课的基础：



1. **AAS 本质**：原子核外电子发生**电子能级跃迁**—— 只有电子能级，**没有振动能级和转动能级**，因此产生的是**线光谱**（不是带光谱）。

2. **共振线**：从**基态→第一激发态**的跃迁谱线。它强度最高、发生概率最大，是 AAS 检测的首选分析线。

3. **光源**：要让灯发射待测元素的共振线，灯阴极必须用待测元素制作 —— 这就是**空心阴极灯（HCL）**。十几种元素可用强度更高的**无极放电灯（EDL）**。

4. **火焰原子化器**：按燃气 / 助燃气配比分为中性焰、富燃焰、贫燃焰。缺点是试样利用率仅约 10%。

## 一、石墨炉原子化器（重点，老师详细展开）

### 1.1 基本结构与工作条件

石墨炉是电热原子化器。石墨是良导体，可做很高温度。使用时：



* 内部通 \*\* 氩气（Ar）\*\* 作为保护气，保护石墨管不被氧化烧毁

* 外部接**循环水**降温

* 用**红外温度计**精准控温（老师互动：水银 / 酒精温度计不行，几千 K；红外测温枪 —— 就是疫情期间校门口测体温那种 —— 就是这里用的）

### 1.2 升温四阶段（必考）

老师用国标方法测 Cu/Pb/Cr/Ni 的实际参数表逐项讲解：



| 阶段        | 温度             | 目的            | 时间       |
| --------- | -------------- | ------------- | -------- |
| **① 干燥**  | 20\~120℃       | 除溶剂（主要是水）     | \~50 秒   |
| **② 灰化**  | \~1000K        | 除有机物          | 很快（样品量少） |
| **③ 原子化** | \~2000-2500K   | 真正测定（待测元素原子化） | 仅数秒      |
| **④ 净化**  | 比原子化高 100-200K | 除残渣防残留        | 短        |

老师特别解释了**净化阶段**的意义：假设这次只测到 2500K，有些难解离元素（如铍 Be）没赶出去，下次做就会残留干扰。所以做完后升温 100-200K 把所有东西全部赶出去。

### 1.3 氩气流量与停气



* 氩气流量约 1L/min，大部分时间持续吹扫

* **仅原子化阶段停气**—— 因为此时要检测，需要保持原子浓度稳定；其他阶段一直吹，把废弃物吹走

* 进样量**微升级**（\~20μL）

### 1.4 火焰法 vs 石墨炉法对比（老师要求 "为什么" 两个要点）



| 对比项   | 火焰法              | 石墨炉法                        |
| ----- | ---------------- | --------------------------- |
| 原子化能源 | 火焰热              | 电热                          |
| 试样利用率 | \~10%（90% 随废气浪费） | **>90%**（关在管里）              |
| 试样体积  | \~1mL（连续喷雾）      | μL 级                        |
| 固体进样  | 不行（喷雾喷不了固体）      | **可以**                      |
| 检出限   | \~0.5 ng/mL      | **\~0.002 ng/mL**（低约 100 倍） |
| 重现性   | 好（连续喷雾可平均）       | 较差（一次进样 = 一个数据）             |
| 安全性   | 有明火              | 无明火、密闭、防辐射                  |
| 价格    | 便宜               | 贵（通常带火焰配件）                  |

**老师强调 —— 为什么石墨炉灵敏度比火焰法高？两个原因：**



1. **试样利用率高**（90% vs 10%）

2. **无火焰气体稀释效应**：火焰法中雾滴进入火焰后，溶剂汽化膨胀 + 火焰气体稀释，样品被稀释后才测；石墨炉关在小管里，体积小，无稀释

### 1.5 石墨炉的其他缺点（老师补充）



* 进样位置偏差会影响升温一致性（石墨管中间和两头升温速度不完全一样）

* 以前 48 学时课讲 L'vov 平台技术，现在 36 学时不要求了

## 二、氢化物发生原子化器

### 2.1 原理

不是所有元素都适合 —— 只有能生成**易挥发氢化物**的元素（如砷 As）。

以砷为例：样品 + 硼氢化钾（还原剂）+ 盐酸 → 生成**AsH₃（胂，能飞起来的气态氢化物）**。这个化合物在 \*\*800-1000℃\*\* 就分解为气态基态原子，不需要高温。

### 2.2 仪器结构（老师带学生推导）

既然要反应，就得有**反应瓶**；生成气体后要用气流吹走；吹到原子化器里 —— 但因为只需要 800-1000℃，不需要昂贵的石墨炉或火焰，只要：



* 反应瓶（装硼氢化钾 + 盐酸，磁子搅拌，注射器打进样品）

* 氩气送气

* **防倒吸缓冲瓶**（中学收集气体那种安全瓶原理）

* **石英管**绕电阻丝加热到 800℃—— 极便宜

后面照常接光源 + 检测器即可。老师总结："这套装置非常便宜，但天天只做砷就够用。"

### 2.3 冷原子测汞仪 —— 同一套原理

汞单质本身常温就是气态。测汞是把 Hg²⁺用还原剂还原成 Hg⁰（不是生成氢化物，是还原成单质）。但仪器结构完全一样 —— 只要换还原剂即可。
> 🔍 **Kimi审查修正**：教材/国标冷原子测汞经典还原剂为 **SnCl₂（氯化亚锡）** 或 NaBH₄/KBH₄。老师课上说"碘化钾也行"，但 I⁻ 会与 Hg²⁺ 形成极稳定的 [HgI₄]²⁻ 络合物（β₄≈10³⁰），反而稳定二价汞、不释放 Hg⁰；KI 不作此反应用。[依据：武汉大学《分析化学》]。石英管不加热（冷原子法）。

## 三、仪器结构与特殊机型

### 3.1 通用配置



* **单色器**：UV-Vis 学过的，狭缝宽度影响灵敏度，不重复讲

* **检测器**：统一用**光电倍增管（PMT）**。老师借诺贝尔奖中微子探测举例 —— 南极冰立方中微子探测器核心也是 PMT（捕获中微子碰撞产生的蓝光），AAS 用的是同一类器件

* 仪器类型分类与 UV-Vis 一致：单通道单光束 = 单波长单光束；单通道双光束 = 单波长双光束；双通道双光束 = 双波长双光束。优点缺点全部相同，不重复学

### 3.2 真实仪器：Analyst 800（8 灯架）



* 左边 8 个小柱 =**8 灯架**（实验室只有 4 灯）

* 灯架上虽同时放 8 个灯，但**不是同时测 8 元素**—— 每次通过选灯镜（Lamp Selector Mirror）切换只有一个灯的光进入光路

* 仪器同时带**燃烧头（burner，火焰）和石墨炉（furnace）**，自动切换器（automatic changer）切换

* 光路：灯→选灯镜→原子化器→单色器（monochromator）→检测器

### 3.3 特殊机型：连续光源 AAS（氙灯）



* 传统 AAS 必须用锐线光源（HCL），因为普通连续光源分光分不出足够锐的谱线

* 这台**德国耶拿（Analytik Jena）contrAA**仪器（🔍Kimi审查：老师说"英国"，实际连续光源AAS代表厂商为德国Analytik Jena）用 ** 氙灯（"人造小太阳"，启动电压几万伏，极亮）** 做光源

* 问题：光太强但一次分光不够锐？解法是**两级分光**：棱镜（prism）→光栅（grating），然后到 CCD 检测器

* 结果：谱线宽度～**10⁻³ nm**，而 HCL 能做到**10⁻⁴ nm**

* **老师强调**：谱线越窄灵敏度越高，所以这台氙灯机灵敏度反而低于 HCL 机；但它一个灯替代一箱子 HCL，省事。未来若有更强光源可做三级分光

## 四、谱线干扰（窄带干扰）

老师按 "怎么来的→怎么消除" 的套路讲每类干扰。

### 4.1 发射线干扰



* HCL 阴极合金不纯，在待测共振线旁边还发了一根邻近线，这根线也被吸收→假信号

* **消除**：单色器狭缝收窄只能缓解；最有效是**换次灵敏线**（不用共振线，用待测元素另一根稍弱的线）

### 4.2 吸收线干扰



* 光源没问题，但样品中杂质元素（如 Co）在待测元素共振线附近也有吸收（老师举例 Hg 253.652nm vs Co 253.639nm；🔍Kimi审查：教材标准值为 Co **253.649**nm，老师口误/转写差异）

* 狭缝开小**排不掉**（两根线太近）

* **消除**：同样换一根干扰元素不吸收的次灵敏线；或预先化学分离

## 五、背景吸收（宽带吸收）—— 本节最难

### 5.1 核心概念

**所有背景吸收都是宽带吸收**（带状，\~1nm 宽），与谱线干扰（窄带，10⁻³nm）对立。

### 5.2 四种来源



| 来源        | 具体例子                                                               |
| --------- | ------------------------------------------------------------------ |
| **分子吸收**  | NaCl/KCl <300nm；Ca (OH)₂ 548-560nm；碳氢片段 387-410nm；**硫酸、磷酸 <250nm** |
| **散射光**   | 主要是**瑞利散射**（未蒸发气溶胶颗粒散射光），散射强度∝1/λ⁴。🔍Kimi审查：拉曼散射是荧光/拉曼光谱的概念，不是AAS背景主要来源；AAS分析线固定，不能"改变激发光波长"。 |
| **火焰气体**  | 富燃焰不完全燃烧→碳氢片段；氢气焰只产水所以透光率最高（呼应之前讲的火焰透光率图）                          |
| **石墨炉本身** | 吹扫不干净残留；高温溅射碳粒→散射                                                  |

### 5.3 老师讲的血泪教训（重要实践经验）



* **磷酸根**：学生化的做实验常用磷酸缓冲液（磷酸二氢钾 + 磷酸氢二钠），但磷酸根在 < 250nm 有宽带吸收！→做 AAS 时缓冲体系换**醋酸铵**（pH\~7，易挥发无残留）

* **硫酸**：湿法消解常用浓硫酸，但浓硫酸在 < 250nm 有强背景吸收！→做 AAS 样品消解**不要用浓硫酸，用硝酸**

* 老师讲了真实案例：一个读研学生做实验背景极大，后来发现就是用了浓硫酸 + 磷酸缓冲液，换体系后才做出来

## 六、背景校正技术（四大方法）

老师先画图讲原理：发射线很窄（10⁻⁴nm），原子吸收线稍宽（10⁻³nm），背景吸收极宽（\~1nm，在小范围内近似平的）。测出来的信号 = 原子吸收 + 背景吸收叠加。要扣背景，就是要单独测出背景吸收。

### 6.1 邻近线扣背景（原理铺垫，书上不怎么写）

在邻近位置放一根发射线 —— 背景吸收它，但原子不吸收它（因为原子吸收线很窄）。测一次邻近线 = 测背景，与主信号一减 = 纯原子吸收。**后面三种方法本质都是在制造邻近线。**

### 6.2 自吸收扣背景



* HCL 正常用小电流（mA 级），发锐线

* 把 HCL 电流突然加大→灯内过热→自吸收效应：本来要发宽线，正中间被自己吸收掉，只剩两边邻近线

* 用大电流测一次（= 测背景），小电流测一次（= 原子 + 背景），一减

* **缺点**：大电流伤灯，只能应急偶尔用，不能天天用

### 6.3 塞曼效应扣背景（最高端，常用）



* 在原子化器外加**磁场**→原子能级分裂→谱线分裂为 π 成分（正中）和 σ± 成分（两侧，偏振方向不同）

* 加偏振镜后只选 σ± 成分（邻近线）→测背景

* 优点：仪器上加个磁场 + 偏振镜即可，快速自动，高端机标配

### 6.4 氘灯扣背景（较便宜）



* 氘灯发连续宽带光。宽带光穿过原子化器时：**背景（宽带）大量吸收，但原子（窄线）吸收可忽略**→这一次测得≈纯背景

* 切换：某一时刻用氘灯测背景，下一时刻切回 HCL 测（原子 + 背景），一减

* 老师指仪器图：仪器上自带的那个小灯就是氘灯

老师总结："不管哪种方法，本质都是制造邻近线。"

## 七、其他干扰

### 7.1 电离干扰



* 要测的是**基态原子**，但碱金属 / 碱土金属（Ca/Mg/Sr/Ba）在高温火焰中容易电离→灵敏度损失

* 极端例子：笑气 - 乙炔焰（温度最高）中，🔍Kimi审查修正：教材电离度应为 **Mg ~6%、Ca ~43%、Sr ~84%、Ba ~93%**（按电离能排序：Ba&lt;Sr&lt;Ca&lt;Mg，电离能越低越易电离；原笔记将Ca/Mg颠倒）

* **消除**：①换低温火焰（如氢气焰）；②加**消电离剂**——"flood the flame with electrons"（用电子像洪水淹没火焰）：加大量更易电离的物质（如 KCl、NaCl），它们先电离释放电子，压制待测元素电离。看文献加了钾但不测钾？那就是消电离剂

### 7.2 化学干扰



* 待测元素与样品成分反应生成难解离化合物（如**磷酸钙 Ca₃(PO₄)₂**，极难解离）

* **消除**：


  * 提高火焰温度

  * 用**富燃焰**（还原氛围，还原氧化物）

  * **释放剂**：加 La/Sr 等与磷酸根结合更强的物质，把 Ca 从磷酸钙中抢出来

  * **保护剂 / 螯合剂**：加 EDTA / 柠檬酸等螯合剂把 Ca 包起来（与磷酸根物理隔离）

  * 化学分离（萃取等）

* **磷酸钙例子是要求掌握的**

### 7.3 物理干扰



* 主要是**粘度**影响喷雾效率（火焰法）：🔍Kimi审查修正：粘度过大→雾化效率下降、**雾滴变粗**、提升量减小→灵敏度降低（原笔记"雾滴更细"方向反了）

* **消除方法**：

1. 稀释样品（但浓度已低时不能再稀释）

2. 配与样品粘度一致的标准系列（麻烦）

3. **标准加入法**（重点）

#### 标准加入法详解



* 把样品分成 5-6 等份，每份都有同样的基体 / 粘度

* 第 1 份不加，第 2 份加 M₀标准，第 3 份加 2M₀，第 4 份加 3M₀……

* 测吸光度，外推回归直线到 A=0，横轴截距的绝对值 = 原样品浓度 Cx

* **关键注意**：


  * 标准溶液必须**高浓度小体积**加入（否则改变粘度）

  * 至少 4 个点 + 原样品 = 5 点

  * **不能扣背景**！（把背景也误当成待测信号了）

  * 基体匹配的标准曲线法要求标准系列与样品基体相似

## 八、分析条件选择与定量

### 8.1 条件选择



* **分析线**：一般选共振线；有干扰换次灵敏线

* **狭缝**：窄缝→高灵敏度（但光强弱）

* **灯电流**：小电流防谱线变宽；应急大电流可做自吸扣背景（但伤灯）

* **火焰高度**：不能太尖（不稳）不能太低（溶剂还在挥发），实际试

* **石墨炉**：四阶段温度 + Ar 气流 1L/min

### 8.2 灵敏度与检出限



* 全书通用灵敏度 = 标准曲线斜率（越高越好）

* **AAS 特有：特征浓度** = 产生 1% 光吸收（A=0.0044）所需的待测元素浓度 / 量。**特征浓度越高越不好**（需要更浓才出 1% 吸收）

* 检出限 = 3 倍空白标准偏差对应的浓度（之前讲过）

### 8.3 布置的思考题（下次讲）

两台仪器都有，血清中 Mg 含量已知，火焰法特征浓度 0.02、石墨炉法 2×10⁻²（g，进样 25μL），吸光度最佳范围 0.1-0.6—— 选哪种方法？（提示：倒推哪个方法测出来的 A 落在 0.1-0.6 区间）

## 老师强调的重点 / 考点汇总



1. 石墨炉四阶段名称 + 目的（干燥 / 灰化 / 原子化 / 净化）

2. 火焰 vs 石墨炉：试样利用率 10% vs >90%；检出限差 100 倍；灵敏度高的两个原因

3. 氢化物原子化器：As 等挥发性氢化物元素，石英管 800-1000℃，冷原子测汞同原理

4. 检测器 = PMT；HCL 谱线 10⁻⁴nm vs 氙灯机 10⁻³nm

5. 谱线干扰消除 = 换次灵敏线

6. 背景吸收 = 宽带；硫酸 / 磷酸 < 250nm 有干扰→用硝酸不用硫酸、醋酸铵替代磷酸缓冲液

7. 四种扣背景：自吸收（伤灯应急）/ 塞曼（高端）/ 氘灯（常规）/ 邻近线（原理）

8. 电离干扰消除 = 加消电离剂（K/Na），"flood the flame with electrons"

9. 化学干扰经典例 = 磷酸钙；消除 = 释放剂 (La) 或螯合剂 (EDTA)

10. 标准加入法：高浓度小体积、5 点、不扣背景、消除物理干扰

11. 特征浓度 = 1% 吸收对应浓度，越高越差
