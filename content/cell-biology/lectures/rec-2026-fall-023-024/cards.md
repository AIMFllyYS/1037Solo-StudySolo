## 第一章 细胞连接总览

:::memory{label="1.1 六种细胞连接总览（🔥 高频/必考）" mode="reveal"}

**直接结论**

- **紧密连接 Tight junction**：Claudin / Occludin / JAM（经 ZO-1 衔接）→ **微丝**；堵缝隙 + 膜蛋白极性
- **黏着小带 Adherens junction**：E-cadherin（经 β/α-catenin）→ **微丝**；黏着 + 调控增殖/凋亡/形状
- **桥粒 Desmosome**：非经典 cadherin（desmoglein/desmocollin）→ **中间丝**；牢固铆定
- **间隙连接 Gap junction**：connexin 六聚体（connexon）；无骨架连接；1.4 nm 通讯孔道
- **半桥粒 Hemidesmosome**：特殊整合素 integrin → **中间丝**；锚定基底层（laminin→胶原）
- **黏着斑 Focal adhesion**：αβ 整合素异二聚体 → **微丝**；胶原 / fibronectin

**深度解析**

- 细胞↔细胞用 **cadherin**；细胞↔基质用 **integrin（整合素）**，二者不要搞混。
- 胞内骨架只有**微丝**或**中间丝**两种，**微管不参与**细胞连接。

**助记口诀**

> 紧密黏着桥粒隙，半桥黏着基质接；细胞之间 cadherin，细胞对基质 integrin。

:::

## 第二章 细胞-细胞连接

:::memory{label="2.1 紧密连接（🔥 高频/必考）" mode="reveal"}

**直接结论**

- **功能1 堵缝隙**：水溶性小分子（葡萄糖、蛋白）不能从细胞间隙漏过，保证物质必须穿细胞（受调控）
- **功能2 维持膜蛋白极性**：顶端（apical，肠腔侧）**SGLT 主动转运葡萄糖**；基底侧（basal/lateral）**GLUT 被动转运葡萄糖**出到血液；紧密连接像围栏，不让两种转运体自由扩散混合
- **分子组成**：跨膜蛋白 Claudin / Occludin / JAM；胞内衔接蛋白 **ZO-1** 把它们连到微丝

**深度解析**

- 紧密连接的封闭索（嵴线，sealing strands）在电镜下呈"拉链状"交叉咬合——注意：**"像拉链"这一意象属于紧密连接**，不是桥粒（见 2.3）。

**助记口诀**

> 紧密连接两功能，堵缝加围栏守极性；Claudin/Occludin/JAM，ZO-1 拉微丝。

:::

:::memory{label="2.2 黏着小带 E-cadherin（🔥 高频）" mode="reveal"}

**直接结论**

- **跨膜**：E-cadherin，**Ca²⁺ 依赖**（静息折叠贴膜；胞外 Ca²⁺>1 mM → 构象伸展 → N 端像锁一样结合相邻细胞 cadherin）
- **衔接复合物**：p120-catenin + β-catenin + α-catenin（+vinculin）→ 微丝；cadherin 本身不直接结合微丝
- **特点**：动态，Ca²⁺ 降就解离；功能 = 黏着 + 调控增殖/凋亡/形状
- **Cadherin 异构型**：E-表皮 / N-神经 / P-胎盘，**同型亲同性**（E 只跟 E 结合）

**深度解析**

- 同型亲同性 → 发育早期自动分选：表达 N-cadherin 的细胞聚在一起形成神经组织，表达 E-cadherin 的留在表皮；同一组织内 E-cadherin 表达量高的细胞跑到组织内部、表达量低的留在外层。

**助记口诀**

> E 表皮、N 神经、P 胎盘，同性相吸自动分选；Ca²⁺ 一降就解离，catenin 转接微丝。

:::

:::memory{label="2.3 桥粒 Desmosome（🔥 高频/必考）" mode="reveal"}

**直接结论**

- **跨膜**：desmoglein / desmocollin（非经典 cadherin）
- **胞内骨架**：**中间丝**（不是微丝！）
- **形态**：电镜下电子密度极高、致密斑呈**铆钉 / 纽扣状（斑点状铆定，spot weld）**，极稳定、非常致密规整
- ⚠ **校正**：桥粒**不是"像拉链"**——像拉链/嵴线的是紧密连接的封闭索；桥粒经典描述是**铆钉 / 斑点状**黏附

**深度解析**

- **Adherens vs Desmosome 三点对比**：Adherens 动态（Ca²⁺ 降即解离）、松散、电子密度低、多功能；桥粒**极稳定**（中间丝静态）、致密铆钉状、只做铆定一件事。

**助记口诀**

> 桥粒铆钉连中间丝，紧密连接才像拉链；黏着小带连微丝，两者骨架别记反。

:::

:::memory{label="2.4 间隙连接 Gap Junction" mode="reveal"}

**直接结论**

- **三个层级超分子组装**：Connexin（单体蛋白）→ Connexon（六聚体 = 半个通道）→ Gap junction（两个 connexon 对接 = 12 个 connexin）
- ⚠ **校正**：这是超分子组装的**"三个层级"**，**不是蛋白质"三级结构"**
- **通道直径仅 1.4 nm**：只允许水溶性小分子（cAMP、离子等）通过，蛋白/核酸过不去
- **功能**：物质通讯（不是黏着）；connexin 有 21 种异构型（Cx43、Cx26 等）

**助记口诀**

> 六聚 connexon，对接十二 connexin，1.4 nm 通小分子，通讯不靠黏着力。

:::

## 第三章 细胞-基质连接

:::memory{label="3.1 半桥粒 Hemidesmosome（🔥 高频）" mode="reveal"}

**直接结论**

- 只留桥粒的"一半"（因为是细胞↔基质，不是细胞↔细胞）
- **跨膜**：特殊整合素（integrin）+ 胶原 17
- **配体侧**：层粘连蛋白 laminin（十字架结构）→ 胶原
- **胞内骨架**：中间丝
- **功能**：把上皮细胞锚定在基底层

**深度解析**

- 与黏着斑区分：半桥粒连**中间丝**、配体 laminin；黏着斑是 αβ 整合素连**微丝**、配体胶原/fibronectin。

**助记口诀**

> 半桥粒 integrin 锚中间丝，laminin 十字架接胶原。

:::

:::memory{label="3.2 P-selectin 与白细胞滚动（🔥 高频）" mode="reveal"}

**直接结论**

- **滚动**：内皮细胞上 P-selectin → 识别白细胞表面 PSGL-1（糖基化配体）；相互作用弱、动态，允许沿内皮缓慢移动又不被冲走
- **停住**：感染时细菌趋化因子 → GPCR 信号 → 整合素激活 → 由弱（selectin）变强（integrin-ICAM），细胞停住贴壁
- **穿出**：伸出片状伪足钻出血管 → 追杀细菌

**深度解析**

- 弱（selectin-PSGL-1）→ 强（integrin-ICAM）的结合强度切换，是白细胞从"巡逻滚动"到"粘附穿越血管"的关键。

**助记口诀**

> 选择素弱着滚动，整合素强着停步，片状伪足钻出血管。

:::

## 第四章 细胞外基质与基底层

:::memory{label="4.1 ECM 三大组分" mode="reveal"}

**直接结论**

- **蛋白聚糖 Proteoglycan**：糖为主（GAG 长链 > 蛋白），如硫酸软骨素 / 硫酸乙酰肝素
- **糖蛋白 Glycoprotein**：蛋白为主（含糖修饰），如 **laminin（十字架）、fibronectin（纤连蛋白）**
- **纤维状蛋白 Fibrous protein**：成束长纤维，**胶原蛋白**——人体内含量最高的蛋白，成纤维细胞分泌
- ⚠ **校正**：**透明质酸（HA / 透明质酸）是糖胺聚糖（GAG）**，不与核心蛋白共价连接，严格说**不算蛋白聚糖**

**助记口诀**

> 糖蛋白纤连层粘，蛋白聚糖挂 GAG，胶原成束含量王；透明质酸是 GAG，不挂核心蛋白链。

:::

:::memory{label="4.2 基底层 Basal Lamina（🔥 高频/必考）" mode="reveal"}

**直接结论**

- **来源**：由表皮 / 肌肉 / 内皮细胞**自己分泌**（不是成纤维细胞），位于细胞与结缔组织之间
- ⚠ **校正**：基底层是**四大功能**（不是三大）：
  1. **黏合结构**
  2. **滤过屏障**（如肾血管球：小分子废物透过入尿，大蛋白/细胞挡住）
  3. **抗癌转移屏障**：癌细胞必须分泌酶降解基底层才能侵入血管转移
  4. **指示细胞极性**：靠近基底层 = 底部，对面 = 顶部

**助记口诀**

> 基底层四件事，黏合、滤过、挡癌、定极性；上皮肌肉内皮自己造，癌细胞先拆它才能跑。

:::
