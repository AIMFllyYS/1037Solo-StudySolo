## 一、脂质的分类

### 1.1 总分类
脂质（Lipids）= **脂肪（Fat）+ 类脂**。

- **脂肪 = 甘油三酯（三酰甘油）**：甘油三羟基被三分子脂肪酸酯化
- **类脂（5种，多选题必考）**：
  1. 胆固醇
  2. 胆固醇酯
  3. 磷脂
  4. 糖脂
  5. 鞘脂

### 1.2 甘油三酯
- 结构：甘油三个羟基全被烃链取代 → **非极性、脂溶性、不溶于水**
- 按烃链长度分：长链/中链/短链甘油三酯
- 体内还有少量甘油一酯、甘油二酯（中间代谢物）
- **甘油二酯额外功能：第二信使**（细胞内信号传递）

### 1.3 熔点与脂肪酸组成（生活常识考点）
- 饱和脂肪酸（无双键）→ 熔点高
- 不饱和脂肪酸（含双键）→ 熔点低
- **买油选熔点低的**：含不饱和脂肪酸多，好吸收
- 老师提醒：地铁广告里菜籽油常把"低熔点"作为卖点

## 二、脂肪酸

### 2.1 结构通式
CH₃-(CH₂)n-COOH。动物/植物脂肪酸链长一般14-20碳，**多数为偶数碳**。

### 2.2 两种命名体系（必考）
| 体系 | 从哪端数 | 用途 |
|---|---|---|
| **Δ（Delta）** | 羧基端（-COOH） | 双键位置 |
| **n / ω（omega）** | 甲基端（CH₃-） | 双键位置（常用） |

命名格式：**碳数:双键数-n/ω-双键位置**
- 例：16:0 = 16碳饱和脂肪酸（软脂酸）
- 例：18:1 n-9 = 18碳单不饱和，双键距甲基端9个碳（油酸）

### 2.3 常见脂肪酸（必背）
**饱和脂肪酸**：
- **软脂酸（棕榈酸）= 16碳**
- **硬脂酸 = 18碳**
- 月桂酸(12)、豆蔻酸(14)、花生酸(20)等

**不饱和脂肪酸**：
- 非营养必需：棕榈油酸、油酸、异油酸
- **营养必需脂肪酸（人体不能合成，必须食物供给）**：
  1. **亚油酸**（ω-6）
  2. **亚麻酸**（ω-3）
  3. **花生四烯酸**（由亚油酸代谢产生）
- **EPA / DPA / DHA**：深海鱼油成分，DHA补脑（婴儿奶粉添加），EPA降甘油三酯

### 2.4 ω族不能互变
- ω-3、ω-6、ω-9在体内**彼此不能相互转化**
- 动物只能合成ω-9和ω-7
- ω-6和ω-3必须从食物获得 → 营养必需脂肪酸

## 三、磷脂

### 3.1 两大类
| 类别 | 母体 | 特点 |
|---|---|---|
| **甘油磷脂** | 甘油 | 1,2位烃链，3位磷酸+取代基 |
| **鞘磷脂** | 鞘氨醇 | 神经酰胺为母体 |

### 3.2 甘油磷脂（生物膜双分子层成分）
- 结构：两条疏水尾（1,2位烃链）+ 极性头（磷酸+取代基）
- 细胞膜双分子层：极性头朝外，疏水尾朝内

**常见甘油磷脂（多选题）**：
| 取代基 | 名称 | 特点 |
|---|---|---|
| 无取代 | 磷脂酸 | — |
| 胆碱 | **磷脂酰胆碱 = 卵磷脂** | 大豆、蛋黄富含 |
| 乙醇胺 | **磷脂酰丝氨酸？不——脑磷脂** | 乙醇胺取代 |
| 丝氨酸 | **磷脂酰丝氨酸** | 细胞膜内表面；**细胞凋亡时外翻**（凋亡检测标志） |
| 甘油 | 磷脂酰甘油 | — |
| 双磷脂酰甘油 | **心磷脂** | 线粒体膜丰富 |
| 肌醇 | **磷脂酰肌醇（PIP₂）** | 第二信使前体 |

### 3.3 PIP₂信号通路（老师详细讲）
- PIP₂ = 4,5-二磷酸磷脂酰肌醇
- 激素结合受体 → 激活**磷脂酶C（PLC）**
- PIP₂被裂解为：
  - **DAG（甘油二酯）** → 激活PKC
  - **IP₃（三磷酸肌醇）** → 内质网释钙
- 两者都是第二信使

### 3.4 鞘磷脂与鞘脂
- **神经酰胺 = 鞘氨醇 + 脂肪酸（酰胺键）**
- 神经酰胺的羟基被取代：
  - 被糖链取代 → **鞘糖脂**
  - 被磷酸+胆碱取代 → **鞘磷脂**
- **鞘脂名词解释**：母体含鞘氨醇或二氢鞘氨醇的脂类

## 四、胆固醇

### 4.1 结构
- 母体 = **环戊烷多氢菲**（17个碳的刚性结构，极稳定，**不能被彻底氧化为CO₂+H₂O**）
- 加甲基+短烃链 → 动物胆固醇=**27碳**
- 植物：β-谷固醇=29碳；酵母麦角固醇=28碳

### 4.2 功能
1. **细胞膜成分**（镶嵌在磷脂双分子层中调节流动性）
2. **转化为胆酸**（肝脏生物转化加羟基/羧基增加极性）→ 促进脂类消化吸收
   > 🔍 **Kimi审查修正**：胆酸（胆汁酸）约95%经肠肝循环重吸收，不"代谢为胆色素"。胆色素（胆红/胆绿素/胆素原/胆素）是**血红蛋白**（衰老红细胞破坏）的降解产物，经肝随胆汁排入肠道决定粪/尿颜色——与胆汁酸是两条代谢通路，老师讲课连在了一起。
3. **转化为类固醇激素**（穿膜激素，核受体）
4. **转化为维生素D₃**

## 五、脂质的生物学功能总结

| 脂质 | 主要功能 |
|---|---|
| 甘油三酯 | **储能产热**：1g TG=38kJ，而蛋白质/糖=17kJ；疏水不结合水→体积小；脂肪细胞专门储存 |
| 必需脂肪酸 | 合成前列腺素、血栓烷A₂、白三烯 |
| 磷脂 | 生物膜双分子层；PIP₂=第二信使前体 |
| 胆固醇 | 膜成分；转化胆酸/类固醇/VitD₃ |

### 类二十烷酸（了解）
- **前列腺素（PG）**：五碳环+两条侧链；字母（E/F/A…）表示五碳环取代方式，下标数字1/2/3表示侧链双键数（如PGE₁/PGE₂/PGE₃；PGF系列再标α/β位羟基构型，如PGF₂α）；扩血管、降血压、促平滑肌收缩
  > 🔍Kimi审查：原笔记"PGF₂₁/₂₂/₂₃表示双键数"为转写错误，下标数字是双键总数。
- **血栓烷（TXA₂）**：五碳环变含氧六元环；**促血小板聚集→促血栓**
- **白三烯（LT）**：环打开成直链4个双键；**慢反应物质→过敏反应**（调节白细胞趋化、毛细血管通透性）

## 六、脂质的消化与吸收（重点，对比糖代谢记）

### 6.1 对比糖消化
- **糖**：口腔淀粉酶→单糖→小肠刷状缘**SGLT（Na⁺依赖主动转运）**→**门静脉**入血
- **脂**：疏水，需要预处理→**胆酸盐乳化**→微团→小肠上段消化→两条路径入血

### 6.2 胆酸盐的乳化作用
- 胆固醇在肝脏生物转化→加羟基/羧基→胆酸盐
- 胆酸盐分子：一面极性（亲水），一面非极性（疏水）
- **疏水面结合甘油三酯**，**亲水面结合胰脂肪酶**→把酶铆定在微团表面
- 大微团逐步被水解→小微团→游离脂肪酸

### 6.3 消化酶（小肠上段）
| 底物 | 酶 | 产物 |
|---|---|---|
| 甘油三酯（长链） | **胰脂肪酶 + 辅脂酶** | 2-甘油一酯 + 游离脂肪酸 |
| 磷脂 | 磷脂酶A₂ | 溶血磷脂 + 游离脂肪酸 |
| 胆固醇酯 | 胆固醇酯酶 | 游离胆固醇 + 游离脂肪酸 |

### 6.4 辅脂酶（老师纠错+详解）
- **不是酶**（无活性中心、无催化功能），是辅助蛋白
- 胰腺分泌，以**酶原**形式存在
- 进入十二指肠后被**胰蛋白酶切去N端5肽**→空间构象成熟
- 功能：亲水端结合胰脂肪酶、疏水端结合甘油三酯→把两者拉在一起
- 还能**稳定胰脂肪酶构象**（在脂水界面防止变性）

### 6.5 吸收与两条入血路径（必考）

**路径A：中/短链甘油三酯**
- 分子量小，不需要完全分解
- 肠黏膜细胞内继续水解→游离甘油+游离脂肪酸
- **直接入门静脉**入血

**路径B：长链脂类（绝大部分）**
- 产物：游离脂肪酸+2-甘油一酯+溶血磷脂+胆固醇
- 以混合微团形式被小肠黏膜上皮细胞吸收
- 在胞内**重新合成**TG/胆固醇酯/磷脂
- 与载脂蛋白（**Apo B48/C/A1/A4**）结合→**乳糜微粒（CM）**
- **经淋巴管→胸导管→入血**（🔍Kimi修正：**绕过**肝门静脉，不经过肝脏首过代谢）

### 6.6 小肠黏膜细胞的甘油三酯合成途径——甘油一酯途径（考点）
- 其他细胞：甘油二酯途径
- **肠黏膜细胞特有：甘油一酯途径**
  1. 游离脂肪酸活化：脂酰CoA合成酶+ATP→脂酰CoA（耗2个高能磷酸键=2ATP）
  2. 脂酰CoA转移到2-甘油一酯的1位→甘油二酯（脂酰CoA转移酶）
  3. 再转移到3位→甘油三酯
- **底物：2-甘油一酯**（2位已有烃链）

### 6.7 老师补充：肠道菌群与肥胖
- 肥胖/糖尿病患者小肠屏障破坏、菌群失衡
- 有害菌代谢物增强脂质吸收
- 新疗法：**粪菌移植**重建肠道屏障

## 七、脂肪动员（Fat Mobilization，名词解释必考）

### 7.1 定义
**脂肪细胞内的甘油三酯在脂肪酶催化下逐步水解为游离脂肪酸和甘油，供其他组织氧化利用的过程。**

- 部位：**脂肪组织（脂肪细胞）**
- 时机：饥饿、运动、交感神经兴奋/应激时增强。🔍Kimi审查修正：脂肪动员**在短期饥饿（空腹过夜）时即明显增强**，是饥饿时最先大规模动员的能源；短期饥饿早期先耗尽肝糖原，随后脂肪动员与糖异生并行；长期饥饿时蛋白质分解反而受抑制（蛋白质节俭），脑改用酮体。
- 产物：1分子甘油 + 3分子游离脂肪酸

### 7.2 三步水解与三个酶
| 步骤 | 酶 | 产物 |
|---|---|---|
| 第一步 | **ATGL**（脂肪甘油三酯脂肪酶）+ 脂滴包被蛋白 | TG→DG + FFA |
| 第二步 | **HSL（激素敏感性脂肪酶）= 甘油二酯脂肪酶** | DG→MG + FFA |
| 第三步 | 甘油一酯脂肪酶 | MG→甘油 + FFA |

**关键酶 = HSL**（直接受激素磷酸化调控）

### 7.3 激素调控（多选题必考）
| 脂解激素（促进） | 抗脂解激素（抑制） |
|---|---|
| 胰高血糖素 | **胰岛素** |
| 去甲肾上腺素 | 前列腺素E₂ |
| ACTH | 烟酸 |
| TSH | — |

### 7.4 信号通路（与糖代谢胰高血糖素通路一致）
脂解激素→GPCR→G蛋白→AC→cAMP→PKA→
1. **磷酸化脂滴包被蛋白**→变构→暴露ATGL活性中心→ATGL活化
2. **直接磷酸化HSL**→HSL活化
→ 三步水解释放FFA+甘油

## 八、脂肪动员产物的代谢

### 8.1 甘油的代谢
- **肝脏**（有甘油激酶）：
  - 甘油 + ATP → α-磷酸甘油 → 磷酸二羟丙酮
  - **血糖低时→糖异生往上走→补充血糖**
- **肾/肠**（也有甘油激酶）：
  - 磷酸二羟丙酮**往下走→彻底氧化供能**（节约葡萄糖供脑）

### 8.2 游离脂肪酸——β氧化（核心）

#### Knoop实验（1904年，历史）
- 用苯基标记脂肪酸ω端喂狗
- **偶数碳脂肪酸→尿排苯乙酸；奇数碳→排苯甲酸**
- 推论：脂肪酸从**羧基端**开始，每次β位脱2个碳→β氧化

#### 部位
- 除**脑组织**外所有组织均可
- 最旺盛：**肝脏、肌肉**
- 亚细胞：胞液（活化）+ **线粒体基质**（β氧化循环）

#### 步骤1：活化（胞液）
游离脂肪酸 + CoA + ATP → **脂酰CoA** + AMP
（脂酰CoA合成酶，耗2个高能磷酸键）

#### 步骤2：跨线粒体膜——肉碱穿梭（重点）
- 三个蛋白：**CAT I（线粒体外膜）**+ 转位酶 + CAT II（内膜侧）
- 脂酰CoA →（CAT I）脂酰肉碱 →（转位酶）进入基质 →（CAT II）重新变成脂酰CoA
- **限速酶 = CAT I（肉碱脂酰转移酶I）**

#### 步骤3：四步循环（每轮脱2碳）
| 步骤 | 反应 | 酶 | 产物 |
|---|---|---|---|
| ① 脱氢 | 脂酰CoA → 反Δ²-烯酰CoA | 脂酰CoA脱氢酶 | **FADH₂** |
| ② 加水 | → L-β-羟脂酰CoA | 烯酰CoA水化酶 | — |
| ③ 再脱氢 | → β-酮脂酰CoA | β-羟脂酰CoA脱氢酶 | **NADH** |
| ④ 硫解 | + CoA → 少2碳脂酰CoA + 乙酰CoA | 硫解酶 | **乙酰CoA** |

#### ATP计算（必考）
**软脂酸（16碳）**：
- β氧化次数 = 16/2 - 1 = **7次**
- 乙酰CoA = 8个（每个10ATP）= 80
- FADH₂ = 7个（每个1.5ATP）= 10.5
- NADH = 7个（每个2.5ATP）= 17.5
- **生成合计 = 108 ATP**
- 活化耗2ATP → **净生成 = 106 ATP**

**18碳硬脂酸**：8次β氧化，9乙酰CoA → 90+8×1.5+8×2.5=90+12+20=122-2=120（课后自算）

#### 乙酰CoA的去向
- 大部分组织：直接进TCA彻底氧化
- **脑组织不能用脂肪酸**：肝脏把乙酰CoA变成**酮体**→透过血脑屏障→脑利用（肝内生酮，肝外利用）

## 九、其他氧化方式

### 9.1 不饱和脂肪酸
- 天然双键是**顺式**，β氧化第一步生成反式烯酰CoA
- 需要**异构酶**：顺→反，或D型β-羟→L型，才能继续β氧化

### 9.2 超长链脂肪酸（通常指≥C22，如神经酸24:0、蜡酸26:0；DHA 22:6为例）
> 🔍Kimi审查：EPA是20碳，不属">20碳"超长链；超长链脂肪酸主要指C22及以上，在**过氧化物酶体**中β氧化。
- 先在**过氧化物酶体**中β氧化剪短
- 再回到线粒体彻底氧化

### 9.3 奇数碳脂肪酸
- 每次脱2碳，最后剩3碳 = **丙酰CoA**
- 路径：丙酰CoA →（羧化）D-甲基丙二酰CoA →（消旋）L-甲基丙二酰CoA →（变位酶，B₁₂）**琥珀酰CoA** → TCA循环（琥珀酸→延胡索酸→苹果酸→草酰乙酸→PEP→丙酮酸→乙酰CoA→TCA）

### 9.4 ω氧化（内质网）
- 甲基端氧化为羧基→α,ω-二羧酸→两端都可β氧化
- 了解即可

## 老师强调的重点/考点汇总

1. 脂质=脂肪+类脂；类脂5种（胆固醇/胆固醇酯/磷脂/糖脂/鞘脂）
2. 软脂酸16碳、硬脂酸18碳；必需脂肪酸=亚油酸/亚麻酸/花生四烯酸
3. ω-3/6/9不能互变；EPA/DHA来自鱼油
4. 磷脂酰丝氨酸外翻=凋亡标志；心磷脂=线粒体膜；卵磷脂=胆碱取代
5. 胆固醇=环戊烷多氢菲27碳，不能彻底氧化
6. TG储能38kJ/g vs 糖/蛋白17kJ/g
7. 消化：胆酸盐乳化+胰脂肪酶+辅脂酶；长链→乳糜微粒→淋巴管；中短链→门静脉
